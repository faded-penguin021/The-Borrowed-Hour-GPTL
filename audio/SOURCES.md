# Audio sample library

All files in this directory are **CC0** ("no rights reserved"). They are
served via jsDelivr from this repo's `main` branch:

```
https://cdn.jsdelivr.net/gh/faded-penguin021/The-Borrowed-Hour-GPTL@main/audio/<category>/<name>.mp3
```

The `AmbienceEngine` in `index.html` lazy-fetches them; missing files
fail silently (warn-once in the console) and the engine falls through to
music-only output for that lane.

## Format requirements

- **Codec**: MP3, mono.
- **Bitrate**: 64 kbps.
- **Loudness target**: −18 LUFS (integrated) for loops; −15 LUFS short-term peak for one-shots.
- **Loops** (`space/`, `population/`): 12–15 seconds, seamlessly looping (no clicks at the loop point).
- **One-shots** (`events/`): 0.4–3 seconds, fully decayed at the end.
- **Filename**: exactly matches the enum value, e.g. `intimate.mp3`, `bell_toll.mp3`.

Total expected budget: ~35 files, ~2 MB on disk.

## Attribution log

**Current state: all 35 files are procedurally synthesized placeholders.**

They were generated by `generate.sh` in this directory using ffmpeg's
built-in sine / coloured-noise / filter primitives — no copyrighted source
material is involved. All placeholders are dedicated to the public domain
(CC0) by their author. Re-run `bash audio/generate.sh` from the repo root
to regenerate them in place.

The placeholders are obviously synthetic (a brown-noise wash for "intimate"
rather than a recorded small room; a layered-sine bell rather than a
recorded bell). The engine routes audio correctly with them, and the
sound design conveys the right gross category (low rumble vs. high
shimmer; rhythm vs. stasis), but for shippable polish each file should
eventually be replaced with a real CC0 field recording from a source like
Freesound (CC0 dedication only), archive.org, or a custom recording session.

When swapping in a real recording:

1. Encode it to mono 64 kbps mp3 at 44.1 kHz, matching the format above.
2. Name it exactly to match the enum value (e.g. `bell_toll.mp3`).
3. Drop it into the appropriate subdirectory, overwriting the placeholder.
4. Add a line below with source URL and CC0 attestation.
5. Adjust `AMBIENCE_SPACE_TRIM` / `AMBIENCE_POPULATION_TRIM` /
   `AMBIENCE_EVENT_TRIM_DEFAULT` in `index.html` if loudness shifts
   noticeably from the placeholder.
