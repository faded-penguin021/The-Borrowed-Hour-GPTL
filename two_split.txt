// =============================================================================
// THE BORROWED HOUR — ARCHITECTURE NOTES
// =============================================================================
//
// A literary, mood-driven interactive text adventure. Five premises (Echo /
// Neon / Omen / Dream + a Wild custom-scenario builder), each one a contained
// "hour" with a defined good ending and bad ending. The aesthetic is
// twilight-and-cream serif, typewriter reveal, narrative-flavored loading
// phrases — the wait is part of the texture.
//
// -----------------------------------------------------------------------------
// MODEL STRATEGY (two-tier)
// -----------------------------------------------------------------------------
// Sonnet 4.6 writes the opening scene only — 4500 max_tokens at temp 0.85.
// The opening is the longest single piece of atmospheric prose in any chronicle
// and sets the voice for everything that follows; paying for the higher tier
// once is justified by what the rest of the hour inherits from it.
// Haiku 4.5 carries every subsequent in-fiction turn (3500 max_tokens, temp
// 0.6) and the post-game meta-discussion. Net cost is roughly 30-40% of an
// all-Sonnet implementation.
//
// MODEL_OPENING uses the unpinned 'claude-sonnet-4-6' alias so the artifact
// auto-upgrades to future Sonnet 4.x snapshots. MODEL_CONTINUATION is pinned
// to a specific Haiku 4.5 snapshot for stable behavior across iterations on
// the prompt — Haiku revisions are more likely to shift the carefully tuned
// rule-following and stylistic register than Sonnet revisions are.
//
// -----------------------------------------------------------------------------
// PROMPT CACHING
// -----------------------------------------------------------------------------
// The system prompt and GM_TOOL schema are ~5–8K tokens combined and stay
// identical for every in-fiction turn within a single chronicle. Anthropic's
// prompt caching lets us pay full input price for the first turn that builds
// the cache and ~10% of that price for every subsequent turn that lands
// within the TTL.
//
// TTL: 1 HOUR, explicit. Interactive fiction has human pacing — turn-to-turn
// gaps of 5–15 minutes are normal as the player reads narration, decides,
// types. The 5-minute default (which Anthropic silently switched to in March
// 2026; previously 1h was the implicit default) expires the cache on most
// turns, forcing every call to pay full input price for the system+tools
// prefix. The 1h TTL doubles the write surcharge (2x base input vs 1.25x for
// 5m), but we pay that exactly once per chronicle and then ride cache reads
// for everything that follows. For interactive fiction the math always
// favors 1h. The TTL is set explicitly via `ttl: "1h"` on the cache_control
// block in callAPI — relying on the default would silently fall back to 5m.
//
// Implementation: callAPI takes an optional `cache` flag. When set, the
// system prompt is sent as a typed content block with cache_control on it
// instead of as a raw string. Per the Anthropic prefix hierarchy
// (tools → system → messages), a single breakpoint at the end of system
// caches BOTH the tool schema and the entire system prompt — messages stay
// uncached and reprocess every turn, which is what we want since they're
// the rolling part.
//
// Haiku 4.5 requires at least 4096 tokens in the cached prefix for caching
// to actually engage; under-minimum requests silently skip caching with no
// error returned. system + GM_TOOL clear that comfortably from turn 1.
// Sonnet 4.6's minimum is 2048.
//
// We DO cache the Haiku continuation turns and the Haiku meta-mode turns —
// both reuse a large, stable prefix across multiple requests in close
// succession.
//
// We DO NOT cache the Sonnet opening, for two independent reasons:
//   (a) caches are scoped per-model, so a Sonnet write cannot serve a Haiku
//       read — the opening's cache cannot help the continuations that follow;
//   (b) the opening fires exactly once per chronicle, so even within Sonnet
//       there is no subsequent call within the TTL to amortize the write
//       surcharge against. The one edge case where it would help is a retry
//       on a malformed opening within the TTL window; retries are rare and
//       the absolute cost difference is a fraction of a cent either way.
//
// SECOND BREAKPOINT — rolling window on message history. In addition to the
// system+tools breakpoint above, we attach a second cache_control on the
// last historical assistant message (the one just before the new user turn)
// in the in-fiction submit path. Because every historical message has been
// deterministically stripped via stripHistoricalUser / stripHistoricalAssistant,
// the bytes are byte-identical turn-to-turn for any message that has already
// scrolled into "historical" position. The cache layer matches the longest
// stable prefix, so each turn reads the full chronicle prefix from cache and
// only pays full input price for the new user message (which carries the
// current state snapshot — necessarily uncached, it changes every turn).
//
// Earlier versions of this comment claimed the second breakpoint would
// require restructuring assistant content from JSON strings into typed
// tool_use blocks. That was overcautious: wrapping the existing string in
// a typed text content block with cache_control is a sufficient and minimal
// change. The model still reads the text content the same way.
//
// The third breakpoint sits on the meta-mode chronicle: the post-game
// assistant acknowledgment that follows the large chronicle dump carries a
// cache_control, so all subsequent meta turns read the chronicle from cache
// instead of reprocessing 10–40K tokens of stored playthrough every turn.
//
// Anthropic supports up to 4 cache breakpoints. We currently use 2 in the
// in-fiction path (system+tools, history) and 2 in meta mode (system+tools,
// chronicle). Room for a 4th if a future need arises.
//
// -----------------------------------------------------------------------------
// STATE MACHINERY
// -----------------------------------------------------------------------------
// Every in-fiction turn is forced into a `narrate_and_update_state` tool call
// via tool_choice. The schema has:
//   gm_scratchpad   — private GM working space; carries explicit boundary
//                     and style checks every turn (see "Public/hidden" below)
//   narration       — player-facing prose
//   state           — public fields: scene, time, inventory, npcs, clues,
//                     summary, plus a hidden_state field for GM bookkeeping
//   ending          — one of "good" | "bittersweet" | "pyrrhic" |
//                     "ambiguous" | "bad", optional. See the ENDINGS
//                     section below.
//
// State is currently returned in FULL on every turn rather than as diffs.
// An earlier version of this comment claimed "the model lost things when we
// tried diffs" — that was inferential confabulation, not observation; diffs
// were never actually tested. The strong empirical claim is retracted.
//
// The legitimate engineering case against pure diffs still has weight (errors
// in incremental updates compound across turns; full state recovers on the
// next turn from any single omission), but it's a tradeoff to evaluate, not
// a settled rejection. The current output-growth pressure at long chronicles
// is being addressed first via ACTIVE PRUNING (see the system prompt under
// "STATE PRUNING") — full state every turn, but the state itself is actively
// trimmed when NPCs go inactive or clues resolve. If pruning proves
// insufficient at turn 30+, an ops-based diff schema (per-turn additions,
// updates, archivals) is the queued next lever.
//
// -----------------------------------------------------------------------------
// PUBLIC vs HIDDEN — THE CENTRAL DESIGN TENSION
// -----------------------------------------------------------------------------
// The single most fragile load in the design is the public/hidden boundary.
// Public state fields (the player's diary) must reflect ONLY what the player
// has been shown in narration. Hidden state holds everything else: clocks,
// twists, secret allegiances, NPC private motives, faction names not yet
// voiced aloud, the prices NPCs would charge for specific revelations.
//
// The system prompt frames public state positively as "the player's diary,
// written in their voice" and warns explicitly against INFERENTIAL COMPRESSION
// — the failure mode where the model collapses two evidentiary steps into one
// confident assertion (e.g. "Threll confirmed as the assassin" when the player
// was only shown that Ardrel claims to have seen Threll wearing a matching
// ring). Three to four worked WRONG/RIGHT examples follow, drawn from real
// playthroughs. Schema vocabulary itself ("disposition," "faction,"
// "warmth," "wariness") is explicitly forbidden from leaking into the diary —
// these are GM concepts, not player vocabulary.
//
// -----------------------------------------------------------------------------
// NPC DISPOSITION & FRICTION-ON-REVELATIONS
// -----------------------------------------------------------------------------
// NPCs have a qualitative disposition (warm / wary / guarded / opposed) that
// shapes voice and what they offer freely. The critical rule is friction
// lives on REVELATIONS, not on PERSONALITIES — the failure mode of naive
// "add friction" instructions is uniform stonewalling, where every NPC
// becomes grudging and the world feels tightly clenched. Cheap things flow
// freely; load-bearing revelations cost something. NPCs do not optimize the
// player's strategy; their advice is a character opinion, not an oracle.
//
// -----------------------------------------------------------------------------
// HISTORY MANAGEMENT
// -----------------------------------------------------------------------------
// Trim at >60 messages: keep the first 2 (the opening exchange) plus the 44
// most recent. These constants were raised from 40/28 after state-stripping
// landed (see below) — stripped historical pairs are roughly 10x cheaper
// than they used to be, so a wider memory window is now affordable without
// triggering the rule-following degradation that drove KEEP_RECENT down to
// 28 originally. Char cap at 80K (was 140K); under stripping it's nearly
// impossible to hit through legitimate play, but kept as a backstop.
//
// STATE STRIPPING. The React `history` state is kept pristine — undoLastTurn
// re-parses the latest assistant message to restore gameState, and the
// meta-mode chronicle reconstruction reads narration out of stored JSON.
// For the API payload itself we derive an `apiHistory` where everything
// except the trailing un-stripped pair has its state payload removed:
// historical user messages keep only the [Player action] block; historical
// assistant messages keep gm_scratchpad + narration (+ ending) and drop the
// state object entirely. The current state is always in the newest user
// message anyway, so older state snapshots are stale and redundant. See
// stripHistoricalUser / stripHistoricalAssistant for the implementation.
//
// The rolling 'summary' field is the long-term memory once older turns scroll
// out. A turn that promotes hidden material into the summary contaminates
// every subsequent turn — hence the heavy emphasis on the public/hidden
// boundary in the prompt.
//
// -----------------------------------------------------------------------------
// CONSIDERED AND DELIBERATELY NOT BUILT
// -----------------------------------------------------------------------------
// Documenting these so future-me doesn't re-litigate. Each was evaluated
// against playthrough evidence and found to add complexity without enough
// quality gain over prompt-level fixes:
//
// (1) Two-Haiku split: NOW BUILT. See "GM/NARRATOR SEPARATION" below.
//     Prompt-level fixes (positive-frame diary, worked examples, vocabulary
//     policing) proved insufficient on extended replay — inferential
//     compression and epistemic leakage persisted. The structural split
//     addresses both at the source: the Narrator literally cannot leak what
//     it never sees.
//
// (2) Post-turn audit pass (cheap second Haiku call that rewrites the four
//     public state fields from narration text alone, blind to hidden_state).
//     Theoretically clean: cannot compress inferences it doesn't have evidence
//     for. Actual cost adder is small. SUPERSEDED by the GM/Narrator split,
//     which solves the same problem more fundamentally — the Narrator never
//     sees hidden_state, so its output cannot contain it. The audit pattern
//     remains available as a defense-in-depth layer if edge cases surface.
//
// (3) Variable temperature across in-fiction turns (e.g. every 4th turn at
//
// -----------------------------------------------------------------------------
// GM/NARRATOR SEPARATION (Tier 2)
// -----------------------------------------------------------------------------
// The single most fragile load in the original design was the public/hidden
// boundary — a single model seeing the full state while writing both logic
// AND prose, relying on prompt-level discipline to not leak hidden state
// into narration. Prompt-level fixes (worked examples, diary framing,
// vocabulary policing) proved insufficient on extended replay: inferential
// compression and epistemic leakage persisted as RLHF artifacts.
//
// The structural fix: split each continuation turn into two sequential
// Haiku calls.
//
// CALL 1 — GM LOGIC (gm_decide tool):
//   Sees: full state (public + hidden), conversation history, player action.
//   Produces: gm_scratchpad, updated state (with hidden_state), narrator_brief,
//   and optionally ending. Does NOT produce narration prose.
//   The narrator_brief is the bridge: a concise description of what the
//   Narrator should write, containing ONLY information the player is allowed
//   to see. The GM writes it knowing the Narrator is blind to hidden_state.
//
// CALL 2 — NARRATOR (narrate_turn tool):
//   Sees: premise seed (for atmosphere), public state ONLY (no hidden_state),
//   recent narration history (for voice continuity), the narrator_brief.
//   Produces: narration prose only.
//   The Narrator NEVER sees hidden_state, gm_scratchpad, or GM-only notes.
//   It literally cannot leak what it never receives.
//
// The opening scene remains a single Sonnet call — it uses the stronger model
// with better boundary compliance, has no history to contaminate, and needs
// maximum coherence between opening prose and initial state.
//
// COST: ~30-40% increase per continuation turn (two Haiku calls instead of
// one). Both calls are cached (system+tools on each), so the marginal cost
// is dominated by the narrator_brief token overhead and the second call's
// output tokens. At Haiku 4.5 pricing ($1/$5 per MTok) this is roughly
// $0.002-$0.004 per turn — negligible against the quality gain.
//
// LATENCY: the two calls are sequential (the Narrator needs the GM's brief),
// so wall-clock latency roughly doubles. Mitigated by (a) the GM call
// producing less output (no prose), (b) the Narrator call having a smaller
// context (no hidden state, no full history), and (c) both reading from
// cache. Typical added latency is 1-2 seconds per turn.
//
// -----------------------------------------------------------------------------
//
// (3) Variable temperature across in-fiction turns (e.g. every 4th turn at
//     0.85 instead of 0.6). The mechanism is real — autoregressive sampling
//     causes prose patterns to self-reinforce within the active window,
//     producing the kind of crutches we observed in playthroughs ("X with
//     the [trait] of someone who [experience]" repeated across many NPCs).
//     Pulled because it muddied attribution: with prompt-level prose-variety
//     guidance AND the scratchpad STYLE CHECK AND temperature variance all
//     introduced at once, there was no way to tell which intervention closed
//     the gap on replay. Held in reserve as the next lever if the prompt
//     interventions don't suffice.
//
// (4) Free-text language input. Curated list instead — covers what Claude
//     handles natively at high quality, and avoids the prompt-injection-shaped
//     attack surface a free-text language field would open up.
//
// -----------------------------------------------------------------------------
// REQUEST CANCELLATION
// -----------------------------------------------------------------------------
// A single AbortController per in-flight request chain lets the player kill
// a long-running call from the UI. The reference lives in `abortRef`, freshly
// allocated on every beginAdventure / submit and nulled in the finally block.
// callAPI's optional `signal` argument threads down into fetch, and the retry
// loop's catch detects AbortError BEFORE its network-error branch — otherwise
// a cancelled request would be silently retried twice more before the player's
// intent surfaced. Aborted calls re-throw as BorrowedError with a "Request
// cancelled by the player" detail; the call sites in beginAdventure and
// submit recognize that detail and roll state back WITHOUT raising the error
// banner, since a player-initiated cancel isn't a failure. The STOP control
// renders inline next to the loading phrase whenever a request is live.
//
// -----------------------------------------------------------------------------
// WILD MODE — OBJECTIVE NEGOTIATION
// -----------------------------------------------------------------------------
// Player-authored seeds vary wildly in how much they commit to. "I am a
// lighthouse keeper, winter, something is climbing the stair" is rich on
// atmosphere and silent on objective. The old approach asked the model to
// silently INFER a goal and commit before turn 2 — which works when the
// inference is right and fails uncomfortably when it isn't.
//
// The current approach: when the seed does not commit to an objective, the
// model does NOT silently commit either. Instead, within the first 2–3 turns
// the WORLD poses the question through fiction — a stranger asks, a map
// presents choices, an internal pull surfaces. The player's response (or
// their refusal to respond) becomes the objective. Resistance is itself a
// valid story: a character who refuses to commit to a goal IS the goal.
//
// This is gated. When the seed already commits ("escape the trap," "deliver
// the message," "find my sister"), the model accepts the stated objective
// and proceeds — no negotiation theatre, no in-fiction quiz.
//
// -----------------------------------------------------------------------------
// AUTHORIAL VOICE
// -----------------------------------------------------------------------------
// The system prompt now carries an explicit voice anchor: a writer who
// notices textures more than faces, who trusts silence, whose sentences are
// short until they suddenly aren't. The bullet names Borges, Le Guin, and
// Ishiguro as register-anchors — not as imitation targets. The pairing with
// a concrete contrast example ("not 'the air was tense' but 'the room held
// its breath, and someone's glass touched the table with a sound like a
// small confession'") gives Haiku a tangible direction in addition to the
// abstract one.
//
// This is additive to, not a replacement for, the existing prose-variety
// guidance on character introduction. The two work in alternation: faces
// AND textures, varied turn to turn.
//
// -----------------------------------------------------------------------------
// ENDINGS — FIVE TYPES, NOT TWO
// -----------------------------------------------------------------------------
// The ending enum carries five values: good, bittersweet, pyrrhic, ambiguous,
// bad. The expansion exists because Dream's "helped Mara go in peace" is
// already bittersweet rather than good, and Echo's "consented to stay in
// the loop" is pyrrhic rather than bad. The narrower binary forced
// emotionally complex outcomes into the wrong bucket.
//
// The five values are still kinds of success and kinds of failure — they
// are NOT a softer middle the model can use to dodge commitment. The
// system prompt's ENDING THE CHRONICLE section enforces this: an
// ambiguous ending is a story whose resolution genuinely refuses closure,
// not a story whose ending the model is reluctant to commit to. Each
// scenario's gmNote contains specific guidance on what each of the five
// types looks like in that scenario's emotional range.
//
// -----------------------------------------------------------------------------
// FILE LAYOUT (top to bottom)
// -----------------------------------------------------------------------------
//   1.  This architecture comment.
//   2.  buildCustomPremise — factory for wild (player-authored) premises.
//   3.  PREMISES array — the four built-in scenarios, each with seed + gmNote.
//   4.  Model constants (MODEL_OPENING, MODEL_CONTINUATION) and LANGUAGES list.
//   5.  EMPTY_STATE shape.
//   6.  GM_TOOL — opening-scene schema (single Sonnet call).
//       GM_LOGIC_TOOL — continuation GM logic schema (split architecture).
//       NARRATOR_TOOL — continuation narrator prose schema (split architecture).
//   7.  buildSystem(premise, language) — opening-scene system prompt.
//       buildGMSystem(premise, language) — continuation GM logic prompt.
//       buildNarratorSystem(premise, language) — continuation narrator prompt.
//   8.  buildMetaSystem(premise, language) — post-game discussion prompt.
//   9.  parseGMResponse, parseGMLogicResponse, parseNarratorResponse + helpers.
//   10. STYLES — the CSS template literal.
//   11. App — the main React component (state, handlers, top-level render).
//   12. TitleScreen, GameScreen, and modal subcomponents.
// =============================================================================

The seed may commit to an objective ("escape the trap," "deliver the message," "find my sister," "survive the night," "solve the mystery") — or it may stay silent and atmospheric, all situation and no stated goal. The two cases are handled differently.

Reserve this for stories that GENUINELY refuse closure, not for stories you are reluctant to commit to.
- BAD: The player dies, fails irrevocably, or chooses a path that severs the way back. Narrate without flinching.

// Custom error type that carries both the in-character line shown to the
// player and a technical detail line useful for debugging. The renderer
// shows the in-character line as the primary message and the detail as
// a smaller, dimmer aside underneath. Plain Error objects (e.g. from
// network code we don't control) display only the message.
class BorrowedError extends Error {
  constructor(message, detail) {
    super(message);
    this.name = "BorrowedError";
    this.detail = detail || null;
  }
}

// Map an HTTP status code from /v1/messages to a concrete diagnostic line.
// The strings are deliberately specific — "rate-limited", "model overloaded"
// — so anyone seeing the error knows whether to wait, check credits, or
// file a bug.
const httpStatusHint = (status) => {
  switch (status) {
    case 400:
      return "API rejected the request (HTTP 400 — likely a malformed prompt or schema).";
    case 401:
      return "API authentication failed (HTTP 401 — check your Anthropic API key).";
    case 403:
      return "API forbade the request (HTTP 403 — key may lack access to this model).";
    case 404:
      return "API endpoint or model not found (HTTP 404 — model ID may be deprecated).";
    case 408:
      return "Request timed out before the API responded (HTTP 408).";
    case 413:
      return "Request body too large (HTTP 413 — chronicle history exceeded the limit).";
    case 429:
      return "Rate-limited by the API (HTTP 429 — too many requests, or out of credits).";
    case 500:
      return "API hit an internal error (HTTP 500 — usually transient).";
    case 502:
    case 503:
    case 504:
      return `Anthropic gateway error (HTTP ${status} — usually transient).`;
    case 529:
      return "Anthropic model overloaded (HTTP 529 — try again in a moment).";
    default:
      return `Unexpected API status (HTTP ${status}).`;
  }
};

// Normalize anything thrown into the {message, detail} shape the renderer
// expects. BorrowedError carries detail directly; plain Error / strings get
// shown with no diagnostic line.
const formatError = (e) => {
  if (e instanceof BorrowedError) {
    return { message: e.message, detail: e.detail };
  }
  if (e && typeof e === "object" && typeof e.message === "string") {
    return { message: e.message, detail: null };
  }
  return { message: String(e), detail: null };
};

  return {
    bytes,
    kb: bytes / 1024,
    tokens: Math.round(bytes / APPROX_CHARS_PER_TOKEN),
  };
};

const formatKB = (kb) => {
  if (kb < 1) return `${Math.round(kb * 1024)} B`;
  if (kb < 100) return `${kb.toFixed(1)} KB`;
  return `${Math.round(kb)} KB`;
};

const formatTokens = (t) => {
  if (t < 1000) return `~${t} tokens`;
  return `~${(t / 1000).toFixed(t < 10000 ? 1 : 0)}K tokens`;
};

// Parses the GM's structured JSON response. Returns
// { narration, state, ending, raw, malformed }.
// Robust to occasional model misbehavior (markdown fences, leading/trailing prose).
//
// Why this is more defensive than you'd expect for a tool_choice flow:
// under tool_choice the model SHOULD return a structured tool_use block
// whose input is machine-serialized valid JSON. But when the tool call
// doesn't take — observed in published-artifact environments, where the
// opening Sonnet call can come back as fenced JSON text instead of a
// tool_use block — the model is hand-writing JSON, and hand-written JSON
// from a model producing literary prose routinely has escaping defects:
// literal newlines inside string values, smart quotes, trailing commas.
// callAPI's fallback path returns that text verbatim and we have to cope.
// The repair stage below is best-effort and conservative: every transform
// is followed by a parse attempt, and if nothing yields a usable object we
// still flag malformed rather than guessing.
function tryParseJSON(text) {
  try {
    return JSON.parse(text);
  } catch {
    return null;
  }
}

// Best-effort repair of the JSON defects hand-written model output actually
// exhibits. Each step is independent and followed by a parse attempt by the
// caller. Conservative by design — we would rather fail to repair than
// "repair" into a different valid-but-wrong object.
function repairJSON(text) {
  let t = text;
  // 1. Strip trailing commas before } or ] — the single most common defect.
  t = t.replace(/,(\s*[}\]])/g, "$1");
  // 2. Normalize smart quotes that models sometimes use for JSON structural
  //    quotes. Only the structural ones — we cannot safely touch quotes
  //    inside string values, so this is a narrow replacement of curly
  //    double-quotes that sit where a structural quote belongs (adjacent to
  //    : , { } [ ] or whitespace at a boundary). This is heuristic; if it
  //    doesn't help, the parse just fails and we move on.
  t = t.replace(/[\u201C\u201D]/g, '"');
  // 3. Escape literal newlines/tabs that appear INSIDE string values. The
  //    model sometimes emits a real line break inside narration instead of
  //    \n. We walk the string tracking whether we're inside a JSON string,
  //    and escape raw control chars only when inside one.
  let out = "";
  let inStr = false;
  let escaped = false;
  for (let i = 0; i < t.length; i++) {
    const ch = t[i];
    if (escaped) {
      out += ch;
      escaped = false;
      continue;
    }
    if (ch === "\\") {
      out += ch;
      escaped = true;
      continue;
    }
    if (ch === '"') {
      inStr = !inStr;
      out += ch;
      continue;
    }
    if (inStr) {
      if (ch === "\n") { out += "\\n"; continue; }
      if (ch === "\r") { out += "\\r"; continue; }
      if (ch === "\t") { out += "\\t"; continue; }
    }
    out += ch;
  }
  return out;
}

function parseGMResponse(rawText) {
  let text = (rawText || "").trim();

  // Strip ```json / ``` / ~~~ fences if present. More permissive than a
  // single anchored regex: the model sometimes emits a leading newline
  // before the fence, puts the language tag on its own line, or uses tilde
  // fences. We strip a leading fence line and a trailing fence line
  // independently rather than assuming they're tight against the JSON.
  text = text.replace(/^\s*[`~]{3}[ \t]*[a-zA-Z]*[ \t]*\r?\n?/, "");
  text = text.replace(/\r?\n?[ \t]*[`~]{3}[ \t]*$/, "");
  text = text.trim();

  // Stage 1: parse as-is.
  let parsed = tryParseJSON(text);

  // Stage 2: extract the outermost brace span and parse that. Handles
  // leading/trailing prose the model wrapped around the JSON.
  if (!parsed) {
    const first = text.indexOf("{");
    const last = text.lastIndexOf("}");
    if (first >= 0 && last > first) {
      parsed = tryParseJSON(text.slice(first, last + 1));
    }
  }

  // Stage 3: repair pass, then re-attempt both the whole string and the
  // brace span. This is what catches hand-written-JSON escaping defects.
  if (!parsed) {
    const repaired = repairJSON(text);
    parsed = tryParseJSON(repaired);
    if (!parsed) {
      const first = repaired.indexOf("{");
      const last = repaired.lastIndexOf("}");
      if (first >= 0 && last > first) {
        parsed = tryParseJSON(repaired.slice(first, last + 1));
      }
    }
    if (parsed && typeof console !== "undefined" && console.warn) {
      console.warn("[borrowed] GM response recovered via JSON repair pass");
    }
  }

  // If parsing failed entirely, the parsed thing isn't an object, OR there's
  // no usable narration field — flag malformed and let the caller decide.
  // Critically, we do NOT put rawText into narration here: if the parse
  // failed because the model returned a JSON-shaped tool input, dumping it
  // verbatim would spew JSON at the player. The caller checks `malformed`
  // and triggers a rollback.
  if (
    !parsed ||
    typeof parsed !== "object" ||
    typeof parsed.narration !== "string" ||
    !parsed.narration.trim()
  ) {
    if (typeof console !== "undefined" && console.warn) {
      console.warn("[borrowed] Malformed GM response", { raw: rawText });
    }
    // Build a self-contained diagnostic that surfaces on-screen so a
    // mobile user with no console can still see what shape the raw
    // payload arrived in. Three signals matter:
    //   • length (small = empty/error; very large = could be two
    //     responses fused, or just long)
    //   • does it end in '}' (clean) or mid-token (truncated)
    //   • head + tail snippets so you can eyeball the shape
    const raw = rawText || "";
    const len = raw.length;
    const head = raw.slice(0, 80).replace(/\s+/g, " ");
    const tail = raw.slice(-80).replace(/\s+/g, " ");
    const endsCleanly = /[}\]]\s*$/.test(raw);
    const startsAsJson = /^\s*[{\[]/.test(raw);
    let reasonGuess;
    if (len === 0) {
      reasonGuess = "Raw payload was empty.";
    } else if (!parsed) {
      reasonGuess = endsCleanly
        ? "JSON parse failed despite a clean ending — likely a structural error inside the payload."
        : "JSON parse failed and the payload does not end cleanly — likely truncated.";
    } else if (typeof parsed !== "object") {
      reasonGuess = "Parsed value was not an object.";
    } else {
      reasonGuess = "Parsed object had no usable 'narration' field.";
    }
    const diagnostic =
      `${reasonGuess} ` +
      `Length: ${len}. ` +
      `Starts with JSON: ${startsAsJson ? "yes" : "no"}. ` +
      `Ends cleanly: ${endsCleanly ? "yes" : "no"}. ` +
      `Head: «${head}»${len > 160 ? " … " : " "}Tail: «${tail}».`;
    return {
      narration: "",
      state: null,
      ending: null,
      raw: rawText,
      malformed: true,
      diagnostic,
    };
  }

  const narration = parsed.narration.trim();

  const s = parsed.state && typeof parsed.state === "object" ? parsed.state : {};
  const state = {
    scene: typeof s.scene === "string" ? s.scene : "",
    time: typeof s.time === "string" ? s.time : "",
    inventory: Array.isArray(s.inventory)
      ? s.inventory.filter((x) => typeof x === "string")
      : [],
    npcs: Array.isArray(s.npcs)
      ? s.npcs
          .filter((x) => x && typeof x === "object")
          .map((x) => ({
            name: typeof x.name === "string" ? x.name : "",
            note: typeof x.note === "string" ? x.note : "",
          }))
          .filter((x) => x.name)
      : [],
    clues: Array.isArray(s.clues)
      ? s.clues.filter((x) => typeof x === "string")
      : [],
    summary: typeof s.summary === "string" ? s.summary : "",
    hidden_state: typeof s.hidden_state === "string" ? s.hidden_state : "",
  };

  const ending = VALID_ENDINGS.has(parsed.ending) ? parsed.ending : null;

  return { narration, state, ending, raw: rawText, malformed: false };
}

// True when every tracked field is absent — useful for detecting the case
// where the AI returned valid JSON but silently omitted the state object.
// We use this to keep the prior gameState rather than wipe it on a single
// malformed turn.
function isStateEmpty(s) {
  if (!s) return true;
  return (
    !s.scene &&
    !s.time &&
    !s.summary &&
    !s.hidden_state &&
    (!s.inventory || s.inventory.length === 0) &&
    (!s.npcs || s.npcs.length === 0) &&
    (!s.clues || s.clues.length === 0)
  );
}

// Typewriter component with internal reveal state. Extracting this means the
// 24ms tick during reveal only re-renders this span — not the entire app
// tree, which previously had to walk header buttons, modals, every prior
// entry, and the input row 40 times a second. Major win on mobile.
//
// `instant` skips animation (used for entries already revealed, e.g. loaded
// saves, or globally via the disable-typewriter setting / prefers-reduced-motion).
// `skipSignal` is a counter the parent bumps to jump to end on click.
// `onDone` fires exactly once when reveal completes (naturally or skipped),
// so the parent can mark the entry as fullyRevealed.
//
// We read prefers-reduced-motion at mount as a defensive layer in addition
// to the parent's flag — even if a caller forgot to thread the setting
// through, the OS-level signal alone is enough to silence the typewriter
// for readers who need it.
function TypewriterText({
  text,
  instant = false,
  skipSignal = 0,
  onDone,
  scrollRef,
  fastMode = false,
}) {
  const [reducedMotion, setReducedMotion] = useState(() => {
    if (typeof window === "undefined" || !window.matchMedia) return false;
    return window.matchMedia("(prefers-reduced-motion: reduce)").matches;
  });
  useEffect(() => {
    if (typeof window === "undefined" || !window.matchMedia) return;
    const mq = window.matchMedia("(prefers-reduced-motion: reduce)");
    const handler = (e) => setReducedMotion(e.matches);
    // Older Safari only supports addListener; both branches are cheap.
    if (mq.addEventListener) mq.addEventListener("change", handler);
    else if (mq.addListener) mq.addListener(handler);
    return () => {
      if (mq.removeEventListener) mq.removeEventListener("change", handler);
      else if (mq.removeListener) mq.removeListener(handler);
    };
  }, []);
  const effectiveInstant = instant || reducedMotion;

  const [revealed, setRevealed] = useState(() => (effectiveInstant ? text.length : 0));
  const doneFiredRef = useRef(effectiveInstant);
  const onDoneRef = useRef(onDone);
  useEffect(() => {
    onDoneRef.current = onDone;
  });

  // Reset when text or effectiveInstant changes (rare — happens on save load
  // or when the user toggles the typewriter setting mid-session).
  useEffect(() => {
    setRevealed(effectiveInstant ? text.length : 0);
    doneFiredRef.current = effectiveInstant;
  }, [text, effectiveInstant]);

  // Skip when the parent bumps the signal. Compare against the value at
  // mount so a newly-rendered TypewriterText doesn't instantly skip just
  // because the user has clicked once earlier in the session.
  const initialSkipRef = useRef(skipSignal);
  useEffect(() => {
    if (skipSignal !== initialSkipRef.current) {
      setRevealed((c) => (c < text.length ? text.length : c));
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [skipSignal]);

  // Tell the parent exactly once when reveal completes.
  useEffect(() => {
    if (revealed >= text.length && !doneFiredRef.current) {
      doneFiredRef.current = true;
      onDoneRef.current?.();
    }
  }, [revealed, text.length]);

  // Typewriter loop.
  useEffect(() => {
    if (effectiveInstant || revealed >= text.length) return;

    const tickMs = fastMode ? 22 : 24;
    const charMs = fastMode ? 11 : 12.5;
    const minMs = fastMode ? 1200 : 1500;
    const maxMs = fastMode ? 8000 : 12000;

    const targetMs = Math.max(minMs, Math.min(maxMs, text.length * charMs));
    const ticks = Math.max(1, Math.floor(targetMs / tickMs));
    const stride = Math.max(1, Math.ceil(text.length / ticks));

    const recent = text.slice(Math.max(0, revealed - stride), revealed);
    let delay = tickMs;
    if (recent.includes("\n")) delay = fastMode ? 200 : 220;
    else if (/[.!?…]/.test(recent)) delay = fastMode ? 80 : 90;

    const t = setTimeout(() => {
      setRevealed((c) => Math.min(c + stride, text.length));
    }, delay);
    return () => clearTimeout(t);
  }, [text, revealed, effectiveInstant, fastMode]);

  // Auto-scroll on each tick while typing — gentle, only if the user is near
  // the bottom (so we don't yank them away if they scrolled up to re-read).
  useEffect(() => {
    if (!scrollRef?.current) return;
    const el = scrollRef.current;
    const distanceFromBottom = el.scrollHeight - el.scrollTop - el.clientHeight;
    if (distanceFromBottom < 200) {
      el.scrollTop = el.scrollHeight;
    }
  }, [revealed, scrollRef]);

  const isTyping = !effectiveInstant && revealed < text.length;
  const display = revealed >= text.length ? text : text.slice(0, revealed);
  return (
    <span className={isTyping ? "cursor-blink" : ""}>{display}</span>
  );
}

// Formats the current state into two blocks: a public-state snapshot that
// frames the player action, and a GM-private block that is appended AFTER
// the player action so the negation ("never reveal these") sits adjacent to
// the position of highest salience for the next forward pass. This is
// cheaper than mutating the system prompt every turn (which would kill the
// prompt cache on the static rules block), and it pulls the boundary
// instruction closer to where output is produced.
function formatStateForPrompt(state) {
  if (!state) return { publicBlock: "", privateBlock: "" };
  const lines = ["[CURRENT GAME STATE — authoritative, updated through last turn]"];
  if (state.scene) lines.push(`Scene: ${state.scene}`);
  if (state.time) lines.push(`Time: ${state.time}`);
  if (state.inventory && state.inventory.length) {
    lines.push("Inventory:");
    for (const it of state.inventory) lines.push(`  - ${it}`);
  } else {
    lines.push("Inventory: (empty)");
  }
  if (state.npcs && state.npcs.length) {
    lines.push("NPCs encountered:");
    for (const n of state.npcs) lines.push(`  - ${n.name}: ${n.note}`);
  }
  if (state.clues && state.clues.length) {
    lines.push("Clues / discoveries:");
    for (const c of state.clues) lines.push(`  - ${c}`);
  }
  if (state.summary) lines.push(`Story so far: ${state.summary}`);

  const privateLines = [];
  if (state.hidden_state) {
    privateLines.push(
      "[GM-PRIVATE — invisible to the player. Do not echo, narrate, paraphrase, or hint at any item below. These notes exist only to keep continuity in your own bookkeeping. Anything the player has not yet been shown or told stays here, and stays here this turn.]"
    );
    privateLines.push(state.hidden_state);
  }

  return {
    publicBlock: lines.join("\n"),
    privateBlock: privateLines.join("\n"),
  };
}

// -----------------------------------------------------------------------------
// HISTORY STRIPPING — derived view-model for the API payload
// -----------------------------------------------------------------------------
// React `history` stays pristine (undoLastTurn re-parses the last assistant
// message to restore gameState, and the meta-mode chronicle reconstruction
// reads narration out of stored JSON). For the API payload we derive an
// `apiHistory` where everything except the trailing un-stripped pair has its
// state and scratchpad payloads removed: user messages keep only the
// [Player action] block; assistant messages keep only the narration (+ ending
// when present), dropping both the state object and the gm_scratchpad.
//
// Why strip: the public/private state blocks at the head and foot of every
// user message are large and stale by the time they're historical — the
// current state lives in the newest user message. The gm_scratchpad is
// GM-internal thinking that's already been "used" (its boundary and style
// checks shaped the narration that turn); the scratchpad discipline is
// reinforced every turn by the cached system prompt and tool_choice, not by
// replaying prior scratchpads. Narration alone is what the model needs from
// history — for voice continuity and style anchoring. Stripping cuts a
// historical pair from ~2,000–2,500 tokens to ~150–300 with no information
// loss the model actually uses on later turns.
//
// Why these are pure functions: deterministic same-bytes-from-same-input is a
// prerequisite for any future second cache_control breakpoint inside the
// messages array. Today the cache stops at the end of system, so this is
// just hygiene — but cheap hygiene worth keeping.
//
// Why omit keys rather than stubbing them: tool_choice + GM_TOOL force the
// schema on the model's OUTPUT every turn regardless. Missing keys in
// historical input don't suggest values to imitate; placeholder stubs could
// in principle bait a paranoid model into echoing them. Cleanest is to drop.
function stripHistoricalUser(content) {
  // Extract the [Player action] block. The opening "Begin." carries no marker
  // (it's sent before any state exists) — pass it through unchanged. Stops
  // at the GM-PRIVATE separator or end of string.
  const m = content.match(/\[Player action\]\n([\s\S]*?)(?=\n\n\[GM-PRIVATE|$)/);
  if (!m) return content;
  return `[Player action]\n${m[1].trim()}`;
}

function stripHistoricalAssistant(content) {
  // Content is a stringified tool-input object. Keep only narration (+ ending
  // when present). Drop the state object AND the gm_scratchpad — both are
  // expensive to carry forward and neither contributes to the model's
  // ongoing decisions: state is overridden by the current snapshot in the
  // newest user message, and the scratchpad's discipline (boundary check,
  // style check) is enforced every turn by the cached system prompt and by
  // tool_choice + GM_TOOL on output, not by replay of prior scratchpads.
  // If parsing ever fails on a historical message, return as-is — losing the
  // message would hurt voice continuity more than its token weight costs.
  try {
    const obj = JSON.parse(content);
    const stripped = {
      narration: obj.narration,
    };
    if (obj.ending) stripped.ending = obj.ending;
    return JSON.stringify(stripped);
  } catch {
    return content;
  }
}

export default function BorrowedHour() {
  const [phase, setPhase] = useState("title");
  const [premise, setPremise] = useState(null);
  const [entries, setEntries] = useState([]);
  const [history, setHistory] = useState([]);
  const [input, setInput] = useState("");
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);
  const [ended, setEnded] = useState(false);
  const [gameState, setGameState] = useState(EMPTY_STATE);
  // The player's chosen output language for this chronicle. Set on the title
  // screen before "Begin," persisted with each save, restored on load.
  // Cannot be changed mid-chronicle — the diary is already partly written
  // in the original language and switching would corrupt the record.
  const [language, setLanguage] = useState(DEFAULT_LANGUAGE);
  const [showLedger, setShowLedger] = useState(false);
  const [inputHistory, setInputHistory] = useState([]);
  const [inputHistoryIndex, setInputHistoryIndex] = useState(-1);
  const [metaMode, setMetaMode] = useState(false);
  const [metaMessages, setMetaMessages] = useState([]);
  // Bumped to tell every TypewriterText to jump to fully-revealed. Replaces
  // the old per-entry revealedChars / metaRevealedChars state, which lived on
  // the parent and forced a full re-render every 24ms during typing.
  const [skipNonce, setSkipNonce] = useState(0);

  const [showSaves, setShowSaves] = useState(false);
  const [showCustom, setShowCustom] = useState(false);
  const [showSettings, setShowSettings] = useState(false);
  const [saveList, setSaveList] = useState([]);
  const [saveListLoading, setSaveListLoading] = useState(false);
  const [saveBanner, setSaveBanner] = useState(null);
  // When both clipboard methods fail (mobile Safari quirks), we surface
  // the text in a modal with a pre-selected textarea so the user can
  // long-press → Copy manually. null = modal closed.
  const [exportFallbackText, setExportFallbackText] = useState(null);
  const [loadingPhrase, setLoadingPhrase] = useState("");

  // Reader preferences. Loaded once from window.storage on mount; written
  // back every time they change. Kept separate from save state so toggling
  // a setting mid-chronicle doesn't risk a write conflict with the active
  // save key. Older artifact versions stored nothing here — falling back
  // to DEFAULT_SETTINGS is the right behavior for those readers.
  const [settings, setSettings] = useState(DEFAULT_SETTINGS);
  const settingsLoadedRef = useRef(false);
  useEffect(() => {
    (async () => {
      try {
        const r = await window.storage.get(SETTINGS_KEY);
        if (r?.value) {
          const parsed = JSON.parse(r.value);
          setSettings({ ...DEFAULT_SETTINGS, ...parsed });
        }
      } catch {
        // No prior settings — keep defaults. Don't surface; this isn't a failure.
      } finally {
        settingsLoadedRef.current = true;
      }
    })();
  }, []);
  useEffect(() => {
    // Skip the initial render before settings are loaded; otherwise we'd
    // overwrite the stored settings with DEFAULT_SETTINGS on first paint.
    if (!settingsLoadedRef.current) return;
    (async () => {
      try {
        await window.storage.set(SETTINGS_KEY, JSON.stringify(settings));
      } catch {
        // Silent — a failed settings write is recoverable next session.
      }
    })();
  }, [settings]);
  const updateSetting = (key, value) =>
    setSettings((s) => ({ ...s, [key]: value }));

  // OS-level prefers-reduced-motion. Read live so a system-settings change
  // mid-session is honored. The typewriter component checks this itself
  // (defensive duplication), but having it at the top level also lets us
  // gate other future motion in the app on the same signal.
  const [osReducedMotion, setOsReducedMotion] = useState(() => {
    if (typeof window === "undefined" || !window.matchMedia) return false;
    return window.matchMedia("(prefers-reduced-motion: reduce)").matches;
  });
  useEffect(() => {
    if (typeof window === "undefined" || !window.matchMedia) return;
    const mq = window.matchMedia("(prefers-reduced-motion: reduce)");
    const handler = (e) => setOsReducedMotion(e.matches);
    if (mq.addEventListener) mq.addEventListener("change", handler);
    else if (mq.addListener) mq.addListener(handler);
    return () => {
      if (mq.removeEventListener) mq.removeEventListener("change", handler);
      else if (mq.removeListener) mq.removeListener(handler);
    };
  }, []);
  const instantReveal = settings.disableTypewriter || osReducedMotion;

  // Aggregated size of all saved hours — kept on the parent so the saves
  // modal can display it and the save flow can warn before quota concerns
  // bite. Refreshed on every modal open and after every save/delete.
  const [savesTotalBytes, setSavesTotalBytes] = useState(0);

  const scrollRef = useRef(null);
  const textareaRef = useRef(null);
  // Holds the in-flight request's cancellation handle, or null when nothing
  // is in flight. Shape: { controller, rollback }. The controller's signal
  // is threaded into callAPI/fetch; the rollback is a closure that returns
  // the chronicle to its pre-request state.
  //
  // We carry the rollback in the ref (rather than relying solely on the
  // call-site's try/catch) because cancellation in this runtime cannot
  // depend on fetch actually aborting. Artifacts route api.anthropic.com
  // requests through a sandbox proxy that injects auth headers; that proxy
  // does not always propagate AbortSignal through to the upstream fetch.
  // The signal flips locally, but the network operation continues to
  // completion — so a previous version of cancelRequest that only called
  // abort() left the UI sitting on the loading spinner waiting for a
  // reject that never came.
  //
  // Current strategy: cancelRequest performs the rollback synchronously
  // (loading off, chronicle state restored, input text returned to the
  // box), THEN attempts abort() in case the platform does honor it. If
  // the underlying fetch eventually returns, the call site sees
  // controller.signal.aborted === true after the await and discards the
  // result without touching state. From the player's perspective: STOP
  // is responsive and the chronicle is exactly where they left it.
  const abortRef = useRef(null);

  // Track the actual visible viewport height in a CSS variable. This is the
  // robust mobile fix: when the on-screen keyboard opens (or browser chrome
  // shifts), window.visualViewport reports the smaller visible area and we
  // shrink the layout to match. Falls back to window.innerHeight, then dvh.
  useEffect(() => {
    const setVH = () => {
      const h = window.visualViewport?.height ?? window.innerHeight;
      document.documentElement.style.setProperty("--app-vh", `${h}px`);
    };
    setVH();
    const vv = window.visualViewport;
    if (vv) {
      vv.addEventListener("resize", setVH);
      vv.addEventListener("scroll", setVH);
    }
    window.addEventListener("resize", setVH);
    window.addEventListener("orientationchange", setVH);
    return () => {
      if (vv) {
        vv.removeEventListener("resize", setVH);
        vv.removeEventListener("scroll", setVH);
      }
      window.removeEventListener("resize", setVH);
      window.removeEventListener("orientationchange", setVH);
    };
  }, []);

  // Auto-scroll on structural changes (new entry, loading state changing,
  // meta-mode toggling). Per-tick scroll-during-reveal is handled inside
  // TypewriterText so we don't trigger parent re-renders for it.
  useEffect(() => {
    if (scrollRef.current) {
      const el = scrollRef.current;
      const distanceFromBottom = el.scrollHeight - el.scrollTop - el.clientHeight;
      if (distanceFromBottom < 200) {
        el.scrollTop = el.scrollHeight;
      }
    }
  }, [entries, loading, metaMessages]);

  useEffect(() => {
    if (!saveBanner) return;
    const t = setTimeout(() => setSaveBanner(null), 2400);
    return () => clearTimeout(t);
  }, [saveBanner]);

  // Bump the nonce; every TypewriterText listens for the change and the one
  // currently typing jumps to fully revealed. The others (already revealed)
  // are no-ops on the bump.
  const skipReveal = () => setSkipNonce((n) => n + 1);

  const callAPI = async (
    sys,
    msgs,
    useTool = false,
    model = MODEL_CONTINUATION,
    maxTokens = 3000,
    temperature = 0.6,
    cache = false,
    signal = null,
    tool = GM_TOOL
  ) => {
    // When cache is true, wrap the system prompt as a content block with
    // cache_control on it. Per the Anthropic prefix hierarchy
    // (tools → system → messages), one breakpoint at the end of system
    // caches BOTH the tool schema and the system prompt; messages remain
    // uncached and reprocess every turn. See the PROMPT CACHING section in
    // the architecture comment at the top of this file for the full
    // rationale (why Haiku-yes, why Sonnet-no, minimum prefix lengths, etc).
    //
    // Below-minimum prefixes (under 4096 tokens for Haiku 4.5, under 2048
    // for Sonnet 4.6) silently skip caching — no error is raised — so it is
    // always safe to set cache=true; the worst case is "no effect".
    //
    // The optional `signal` is an AbortController.signal. When the player
    // hits STOP, the controller is aborted and fetch rejects with an
    // AbortError. The retry-loop catch detects it explicitly (before the
    // generic network-error branch) and re-throws as a BorrowedError whose
    // detail line names the cancellation. The call sites in beginAdventure
    // and submit see that detail and roll state back without raising the
    // error banner — a player-initiated cancel is not a failure.
    const body = {
      model,
      max_tokens: maxTokens,
      temperature,
      // 1-hour TTL (instead of the 5-minute default). Interactive fiction has
      // human pacing: players read 100–250 words of narration, decide, type a
      // response — turn-to-turn gaps of 5–15 minutes are normal. At 5-min TTL
      // the cache typically expires between turns and every call pays full
      // input price for system+tools (~6–8K tokens). The 1-hour TTL pays a 2x
      // write surcharge once at chronicle start, then turns on cache reads
      // for the rest of the session at ~10% of base input. Per Anthropic's
      // March 2026 default change, this MUST be set explicitly — relying on
      // the default now means 5 minutes.
      system: cache
        ? [{ type: "text", text: sys, cache_control: { type: "ephemeral", ttl: "1h" } }]
        : sys,
      messages: msgs,
    };
    if (useTool) {
      body.tools = [tool];
      body.tool_choice = { type: "tool", name: tool.name };
    }

    // Retry transparently on rate-limit (429) and server-overload (5xx, 529)
    // responses, which are the most common transient failures. Backoff is
    // ~600ms, ~1.2s, ~2.4s. Non-retryable errors (bad request, auth) throw
    // immediately so the player can correct course rather than wait.
    const RETRYABLE = new Set([408, 429, 500, 502, 503, 504, 529]);
    const MAX_RETRIES = 2;
    let res = null;
    let lastErr = null;
    let lastStatus = null;
    let lastBodySnippet = null;
    for (let attempt = 0; attempt <= MAX_RETRIES; attempt++) {
      if (attempt > 0) {
        await new Promise((r) => setTimeout(r, 300 * Math.pow(2, attempt)));
      }
      // Pre-fetch abort check — if the player cancelled during the backoff
      // delay, don't even issue the next attempt.
      if (signal && signal.aborted) {
        throw new BorrowedError(
          "The hour is set down.",
          "Request cancelled by the player."
        );
      }
      try {
        res = await fetch("https://api.anthropic.com/v1/messages", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify(body),
          signal: signal || undefined,
        });
        if (res.ok) {
          lastErr = null;
          break;
        }
        lastStatus = res.status;
        // Try to capture the first chunk of the body for diagnostic info.
        // We don't display it raw, but it tells us whether the failure is a
        // rate-limit response, an auth message, etc.
        try {
          const bodyText = await res.text();
          lastBodySnippet = bodyText.slice(0, 240);
        } catch {}
        const hint = httpStatusHint(res.status);
        if (!RETRYABLE.has(res.status)) {
          throw new BorrowedError("The hour falters.", hint);
        }
        lastErr = new BorrowedError(
          "The hour falters.",
          attempt < MAX_RETRIES
            ? `${hint} Retrying…`
            : `${hint} Retried ${MAX_RETRIES} times without success.`
        );
        res = null;
      } catch (e) {
        // AbortError must be detected BEFORE the generic network-error
        // branch — otherwise a cancelled request would be silently retried.
        // The DOMException name is 'AbortError'; check that, and also check
        // the signal directly in case the platform surfaces it differently.
        if (
          (e && e.name === "AbortError") ||
          (signal && signal.aborted)
        ) {
          throw new BorrowedError(
            "The hour is set down.",
            "Request cancelled by the player."
          );
        }
        // Network-layer error (no HTTP response at all) — also retry. Likely
        // causes: offline, DNS failure, CORS, browser blocked the request.
        if (e instanceof BorrowedError) {
          // A non-retryable status error from above — re-throw immediately.
          throw e;
        }
        lastErr = new BorrowedError(
          "The hour falters.",
          `Network error before the API responded${
            e?.message ? ` (${e.message})` : ""
          }. Check your connection.`
        );
        res = null;
      }
    }
    if (!res) {
      if (typeof console !== "undefined" && console.warn) {
        console.warn("[borrowed] API failure", {
          status: lastStatus,
          body: lastBodySnippet,
        });
      }
      throw lastErr || new BorrowedError("The hour falters.", "Unknown failure.");
    }
    const data = await res.json();

    // Surface actual token costs per call. Without this we're estimating
    // from chars; with this we have ground truth from Anthropic. The usage
    // object reports:
    //   - input_tokens: uncached input (messages portion + any uncached system)
    //   - cache_creation_input_tokens: tokens written to cache this call
    //     (paid at 1.25x base for 5m TTL, 2x for 1h TTL)
    //   - cache_read_input_tokens: tokens read from cache (paid at 10% of base)
    //   - output_tokens: tokens generated (paid at 5x base for Haiku)
    // A healthy steady-state turn (post turn 1) should show non-zero
    // cache_read_input_tokens and a small input_tokens. If cache_read is 0
    // every turn, caching isn't engaging and we need to investigate.
    if (data.usage && typeof console !== "undefined" && console.debug) {
      const u = data.usage;
      const cacheReads = u.cache_read_input_tokens || 0;
      const cacheWrites = u.cache_creation_input_tokens || 0;
      const inTok = u.input_tokens || 0;
      const outTok = u.output_tokens || 0;
      // Rough cost in USD assuming Haiku 4.5 with 1h TTL cache:
      //   input $1/M, output $5/M, cache_write_1h $2/M, cache_read $0.10/M
      // Sonnet 4.6 differs ($3/M input, $15/M output) — flag the model used.
      const isSonnet = /sonnet/i.test(model);
      const inPrice = isSonnet ? 3 : 1;
      const outPrice = isSonnet ? 15 : 5;
      const cwPrice = isSonnet ? 6 : 2; // 2x base for 1h
      const crPrice = isSonnet ? 0.3 : 0.1;
      const costUSD =
        (inTok * inPrice + cacheWrites * cwPrice + cacheReads * crPrice + outTok * outPrice) / 1e6;
      console.debug("[borrowed] usage", {
        model,
        in: inTok,
        cache_read: cacheReads,
        cache_write: cacheWrites,
        out: outTok,
        total: inTok + cacheReads + cacheWrites + outTok,
        estUSD: costUSD.toFixed(4),
      });
    }

    if (useTool) {
      // tool_choice forces this branch; pull the structured input out of the
      // tool_use block. Per Anthropic's spec `input` is an object, but be
      // defensive: if the API ever returns it as a pre-stringified string,
      // pass it through as-is. parseGMResponse handles both.
      const toolUse = data.content.find(
        (b) => b.type === "tool_use" && b.name === tool.name
      );
      if (toolUse) {
        // Truncation by max_tokens: the tool_use block exists but its input
        // JSON is cut off mid-stream. Returning it would let parseGMResponse
        // flag it as "malformed" without explaining why. Detect here and
        // throw with the actual cause so the on-screen error names it.
        if (data.stop_reason === "max_tokens") {
          throw new BorrowedError(
            "The hour falters.",
            `Tool input was truncated mid-JSON by max_tokens (currently ${maxTokens}). Increase max_tokens or shorten the prompt.`
          );
        }
        if (toolUse.input && typeof toolUse.input === "object") {
          return JSON.stringify(toolUse.input);
        }
        if (typeof toolUse.input === "string" && toolUse.input.trim()) {
          return toolUse.input;
        }
      }
      // Defensive fallback — should rarely fire under tool_choice, but some
      // Claude snapshots emit tool calls as raw <function_calls>/<invoke>/
      // <parameter> markup inside a text content block instead of as a
      // structured tool_use block, and tool_choice doesn't reliably
      // suppress it. When we see the pattern, reshape it into the same JSON
      // the structured path would have returned. If anything's missing or
      // truncated, fall through to the regular text return and let
      // parseGMResponse surface the diagnostic.
      const text = data.content
        .filter((b) => b.type === "text")
        .map((b) => b.text)
        .join("\n")
        .trim();
      if (!text) {
        const stop = data.stop_reason || "unknown";
        throw new BorrowedError(
          "The page came back blank.",
          `Model returned no tool_use and no text. Stop reason: ${stop}.${
            stop === "max_tokens"
              ? " The response hit max_tokens — increase max_tokens or shorten the prompt."
              : ""
          }`
        );
      }
      if (text.includes("<function_calls>") && text.includes("<invoke")) {
        const invokeMatch = text.match(/<invoke\s+name="([^"]+)"\s*>/);
        if (invokeMatch && invokeMatch[1] === tool.name) {
          const params = {};
          const paramRe =
            /<parameter\s+name="([^"]+)"\s*>([\s\S]*?)<\/parameter>/g;
          let m;
          while ((m = paramRe.exec(text)) !== null) {
            params[m[1]] = m[2];
          }
          // The `state` parameter is JSON. Best-effort parse; if it fails
          // (most often because the response was truncated mid-JSON), leave
          // the string in place and let parseGMResponse decide what to do.
          if (typeof params.state === "string") {
            try {
              params.state = JSON.parse(params.state);
            } catch {}
          }
          if (
            typeof params.narration === "string" &&
            params.narration.trim()
          ) {
            if (typeof console !== "undefined" && console.warn) {
              console.warn(
                "[borrowed] Recovered tool call from text-mode <function_calls> emission",
                { model, stop_reason: data.stop_reason }
              );
            }
            return JSON.stringify(params);
          }
        }
      }
      return text;
    }

    const text = data.content
      .filter((b) => b.type === "text")
      .map((b) => b.text)
      .join("\n")
      .trim();
    if (!text) {
      const stop = data.stop_reason || "unknown";
      throw new BorrowedError(
        "The page came back blank.",
        `Model returned an empty response. Stop reason: ${stop}.${
          stop === "max_tokens" ? " Hit max_tokens — increase budget or shorten history." : ""
        }`
      );
    }
    return text;
  };

  const beginAdventure = async (chosen) => {
    setPremise(chosen);
    setPhase("playing");
    setGameState(EMPTY_STATE);
    setLoadingPhrase(pickPhrase(OPENING_LOADING_PHRASES));
    setLoading(true);
    setError(null);
    // Fresh controller + rollback closure for this request chain. The
    // rollback returns the player to the title screen; it's what
    // cancelRequest invokes if the player hits STOP, and also what we
    // invoke ourselves if the request returns but signal.aborted is true.
    const controller = new AbortController();
    const rollback = () => {
      setPhase("title");
      setPremise(null);
    };
    abortRef.current = { controller, rollback };
    try {
      const sys = buildSystem(chosen, language);
      const msgs = [{ role: "user", content: "Begin." }];
      // Higher-tier model for the opening only — sets the tone for the
      // whole hour. All subsequent turns use the cheaper continuation tier.
      // The opening also gets a larger max_tokens budget because it must
      // produce the longest narration of any turn AND populate the full
      // initial state from scratch (no carry-forward summary to lean on);
      // dense premises like Omen otherwise risk truncation.
      const raw = await callAPI(sys, msgs, true, MODEL_OPENING, 4500, 0.85, false, controller.signal);
      // Post-await cancellation check — see the abortRef comment for why
      // this is necessary in addition to the AbortError catch path. If the
      // sandbox proxy didn't propagate the abort, fetch returned normally
      // and we have a valid response; we still need to honor the player's
      // STOP click. cancelRequest already ran the rollback, so we simply
      // return without applying any state.
      if (controller.signal.aborted) return;
      const parsed = parseGMResponse(raw);
      if (parsed.malformed) {
        throw new BorrowedError(
          "The hour stumbles in opening. Try once more.",
          parsed.diagnostic ||
            "Tool response was malformed (likely truncated by max_tokens or missing required fields)."
        );
      }
      setHistory([...msgs, { role: "assistant", content: raw }]);
      setEntries([{ type: "narration", text: parsed.narration, fullyRevealed: false }]);
      if (parsed.state) setGameState(parsed.state);
      if (parsed.ending) setEnded(true);
    } catch (e) {
      // If cancelRequest already handled this turn, skip everything —
      // rollback ran synchronously and loading is already false.
      if (controller.signal.aborted) return;
      // Player-initiated cancel via the old AbortError path. Roll back
      // without surfacing an error banner.
      const cancelled =
        e instanceof BorrowedError &&
        e.detail === "Request cancelled by the player.";
      if (!cancelled) {
        setError(formatError(e));
      }
      // Roll back to the title so the error surfaces somewhere with a way
      // forward — staying on a blank game screen leaves the player stuck.
      rollback();
    } finally {
      // Only clear loading + abortRef if this request is still the active
      // one. cancelRequest may have already nulled abortRef and flipped
      // loading; we don't want to fight it.
      if (abortRef.current?.controller === controller) {
        setLoading(false);
        abortRef.current = null;
      }
    }
  };

  const submit = async () => {
    const text = input.trim();
    if (!text || loading) return;
    if (!metaMode && ended) return;
    skipReveal();

    // Snapshot anything we're about to mutate so a failed API call can
    // unwind cleanly. The player gets their text back, no orphaned action
    // sits in the chronicle, and they can hit Enter to retry.
    const previousInput = input;
    const previousInputHistory = inputHistory;
    const previousInputHistoryIndex = inputHistoryIndex;

    setInput("");
    setInputHistory((h) => (h[h.length - 1] === text ? h : [...h, text]));
    setInputHistoryIndex(-1);
    if (textareaRef.current) textareaRef.current.style.height = "auto";

    if (metaMode) {
      // Meta-discussion turn
      const previousMeta = metaMessages;
      const newMeta = [
        ...metaMessages,
        { role: "user", text, fullyRevealed: true },
      ];
      setMetaMessages(newMeta);
      setLoadingPhrase(pickPhrase(META_LOADING_PHRASES));
      setLoading(true);
      setError(null);
      const controller = new AbortController();
      // Rollback restores the discussion to the moment before Enter and
      // returns the typed text to the input so the player can edit or
      // re-send it. cancelRequest runs this synchronously on STOP.
      const rollback = () => {
        setMetaMessages(previousMeta);
        setInput(previousInput);
        setInputHistory(previousInputHistory);
        setInputHistoryIndex(previousInputHistoryIndex);
      };
      abortRef.current = { controller, rollback };
      try {
        // Build a context: pass the chronicle as background (history of in-fiction
        // exchanges, condensed as user→GM messages), then the meta exchange.
        const sys = buildMetaSystem(premise, language);

        // Build a readable chronicle from history. History contains JSON strings
        // for GM responses and stateful player messages; extract the readable parts.
        const chronicleParts = [];
        for (const h of history) {
          if (h.role === "user") {
            // Strip the [CURRENT GAME STATE] block; keep only the player action.
            const m = h.content.match(/\[Player action\]\s*\n?([\s\S]*)$/);
            const action = m ? m[1].trim() : h.content.trim();
            if (action) chronicleParts.push(`[Player] ${action}`);
            else chronicleParts.push(`[Player] (Begin)`);
          } else {
            // Extract narration from the JSON-encoded GM response.
            const parsed = parseGMResponse(h.content);
            chronicleParts.push(`[GM] ${parsed.narration}`);
          }
        }

        // Cap on very long runs — keep opening + most recent turns.
        const MAX_PARTS = 60;
        let trimmedNote = "";
        let kept = chronicleParts;
        if (chronicleParts.length > MAX_PARTS) {
          const head = chronicleParts.slice(0, 4);
          const tail = chronicleParts.slice(-(MAX_PARTS - 4));
          kept = [...head, ...tail];
          trimmedNote = `\n\n[Note: middle of chronicle abridged for length — ${
            chronicleParts.length - kept.length
          } turns omitted between the opening and the recent passages.]`;
        }

        const { publicBlock, privateBlock } = formatStateForPrompt(gameState);
        const finalState = privateBlock
          ? `${publicBlock}\n\n${privateBlock}`
          : publicBlock;
        const chronicleText = kept.join("\n\n") + trimmedNote;

        // Meta-mode caching: the chronicle text is large (often 10–40K
        // tokens for a full playthrough) and identical across every meta
        // exchange in the post-game conversation. We cache it via a
        // cache_control breakpoint on the assistant acknowledgment that
        // follows the chronicle. This caches the prefix (chronicle user
        // message + acknowledgment) so subsequent meta turns read from
        // cache at 10% of base input price instead of reprocessing the
        // entire chronicle. The newer turns in `newMeta` stay uncached
        // (they change every turn).
        //
        // The system prompt is also cached (callAPI sees cache=true as the
        // 7th argument) — Anthropic supports up to 4 cache breakpoints so
        // both can coexist.
        const metaApiMessages = [
          {
            role: "user",
            content: `For your reference, the full chronicle we just played:\n\n${chronicleText}\n\n— end of chronicle —\n\nFinal game state at the close:\n\n${finalState}`,
          },
          {
            role: "assistant",
            content: [
              {
                type: "text",
                text: "I have the chronicle in mind. I'm ready to talk about it with you.",
                cache_control: { type: "ephemeral", ttl: "1h" },
              },
            ],
          },
          ...newMeta.map((m) => ({ role: m.role, content: m.text })),
        ];
        const reply = await callAPI(sys, metaApiMessages, false, MODEL_CONTINUATION, 3000, 0.8, true, controller.signal);
        // Cancellation can land between fetch resolution and here; honor
        // it without applying state (cancelRequest already rolled back).
        if (controller.signal.aborted) return;
        setMetaMessages([
          ...newMeta,
          { role: "assistant", text: reply, fullyRevealed: false },
        ]);
      } catch (e) {
        if (controller.signal.aborted) return;
        const cancelled =
          e instanceof BorrowedError &&
          e.detail === "Request cancelled by the player.";
        if (!cancelled) {
          setError(formatError(e));
        }
        rollback();
      } finally {
        if (abortRef.current?.controller === controller) {
          setLoading(false);
          abortRef.current = null;
        }
      }
      return;
    }

    // In-fiction turn — TWO-CALL SPLIT (GM logic → Narrator prose)
    //
    // Call 1 (GM logic): Haiku sees the full state (public + hidden),
    //   conversation history, and the player's action. Produces the
    //   gm_scratchpad, updated state (with hidden_state), narrator_brief,
    //   and optionally ending. Does NOT produce narration.
    //
    // Call 2 (Narrator): A fresh Haiku instance sees ONLY the premise seed
    //   (for atmosphere), public state (no hidden_state), recent narrations
    //   (for voice continuity), and the narrator_brief. Produces narration
    //   prose. Cannot leak hidden state because it never sees it.
    //
    // The combined result is stored in history in the same format as the
    // old single-call approach: { gm_scratchpad, narration, state, ending }.
    // All downstream code (stripping, save/load, undo, meta mode) works
    // unchanged.

    const previousEntries = entries;
    const previousHistory = history;
    const newEntries = [...entries, { type: "action", text, fullyRevealed: true }];
    setEntries(newEntries);

    // Build the user message: public state snapshot, the player's action,
    // then the GM-private block last. Keeping the negation right before
    // generation gives Haiku its strongest shot at honoring the boundary.
    const { publicBlock, privateBlock } = formatStateForPrompt(gameState);
    const parts = [];
    if (publicBlock) parts.push(publicBlock);
    parts.push(`[Player action]\n${text}`);
    if (privateBlock) parts.push(privateBlock);
    const playerMessage = parts.join("\n\n");

    const newHistory = [...history, { role: "user", content: playerMessage }];

    // Build apiHistory: stripped view-model for the GM call.
    const tailStart = newHistory.length - 1;
    let apiHistory = newHistory.map((msg, i) => {
      if (i >= tailStart) return msg;
      return msg.role === "user"
        ? { ...msg, content: stripHistoricalUser(msg.content) }
        : { ...msg, content: stripHistoricalAssistant(msg.content) };
    });

    // Trim history if it gets long.
    const TRIM_THRESHOLD = 60;
    const KEEP_RECENT = 44;
    const CHAR_CAP = 80000;
    const charsOf = (msgs) =>
      msgs.reduce((sum, m) => sum + (typeof m.content === "string" ? m.content.length : 0), 0);

    if (apiHistory.length > TRIM_THRESHOLD) {
      const head = apiHistory.slice(0, 2);
      const tail = apiHistory.slice(-KEEP_RECENT);
      apiHistory = [...head, ...tail];
    }
    if (charsOf(apiHistory) > CHAR_CAP) {
      const head = apiHistory.slice(0, 2);
      let tail = apiHistory.slice(2);
      while (tail.length > 4 && charsOf([...head, ...tail]) > CHAR_CAP) {
        tail = tail.slice(2);
      }
      apiHistory = [...head, ...tail];
    }

    if (typeof console !== "undefined" && console.debug) {
      console.debug("[borrowed] apiHistory", {
        msgs: apiHistory.length,
        chars: charsOf(apiHistory),
        estTokens: Math.round(charsOf(apiHistory) / 4),
      });
    }

    setHistory(newHistory);
    setLoadingPhrase(pickPhrase(NARRATION_LOADING_PHRASES));
    setLoading(true);
    setError(null);
    const controller = new AbortController();
    const rollback = () => {
      setEntries(previousEntries);
      setHistory(previousHistory);
      setInput(previousInput);
      setInputHistory(previousInputHistory);
      setInputHistoryIndex(previousInputHistoryIndex);
    };
    abortRef.current = { controller, rollback };
    try {
      // ---------------------------------------------------------------
      // CALL 1: GM LOGIC (gm_decide tool)
      // ---------------------------------------------------------------
      // Uses buildGMSystem (state-management-focused, no prose guidance).
      // Sees the full state including hidden_state. Produces scratchpad,
      // narrator_brief, state, and optionally ending.
      const gmSys = buildGMSystem(premise, language);

      // Cache breakpoint on the last historical message (rolling window).
      const lastHistoricalIdx = apiHistory.length - 2;
      const finalApiHistory = apiHistory.map((m, i) => {
        if (i === lastHistoricalIdx && typeof m.content === "string") {
          return {
            ...m,
            content: [
              {
                type: "text",
                text: m.content,
                cache_control: { type: "ephemeral", ttl: "1h" },
              },
            ],
          };
        }
        return m;
      });

      // GM call: cache=false. In the published artifact environment, wrapping
      // system as a typed content block array (what cache=true does) causes the
      // proxy to stop honoring tool_choice, so the model returns its payload as
      // fenced text instead of a tool_use block. Correctness over cost savings.
      const gmReply = await callAPI(gmSys, finalApiHistory, true, MODEL_CONTINUATION, 2500, 0.35, false, controller.signal, GM_LOGIC_TOOL);
      if (controller.signal.aborted) return;

      const gmParsed = parseGMLogicResponse(gmReply);
      if (gmParsed.malformed) {
        throw new BorrowedError(
          "The hour stumbles. Try once more.",
          gmParsed.diagnostic ||
            "GM logic response was malformed (likely truncated or missing required fields)."
        );
      }

      if (typeof console !== "undefined" && console.debug) {
        console.debug("[borrowed] GM logic complete", {
          briefLen: gmParsed.narrator_brief.length,
          ending: gmParsed.ending,
        });
      }

      // ---------------------------------------------------------------
      // CALL 2: NARRATOR (narrate_turn tool)
      // ---------------------------------------------------------------
      // Uses buildNarratorSystem (prose-focused, literary voice guidance).
      // Sees ONLY public state (no hidden_state), recent narrations for
      // voice continuity, and the GM's narrator_brief. Cannot leak hidden
      // state because it never receives it.

      // Update loading phrase to signal progress.
      setLoadingPhrase(pickPhrase([
        "the ink finds its course",
        "the narrator takes the stage",
        "the words arrange themselves",
        "the prose gathers its voice",
        "the scene composes itself",
      ]));

      if (controller.signal.aborted) return;

      const narratorSys = buildNarratorSystem(premise, language);

      // Build the narrator's context: public state + recent narrations +
      // the brief. The narrator sees NO hidden_state — the firewall.
      const publicState = gmParsed.state;
      const pubLines = [];
      if (publicState.scene) pubLines.push(`Scene: ${publicState.scene}`);
      if (publicState.time) pubLines.push(`Time: ${publicState.time}`);
      if (publicState.inventory?.length) {
        pubLines.push("Inventory: " + publicState.inventory.join(", "));
      }
      if (publicState.npcs?.length) {
        pubLines.push("NPCs known: " + publicState.npcs.map(n => `${n.name} (${n.note})`).join("; "));
      }
      if (publicState.clues?.length) {
        pubLines.push("Clues: " + publicState.clues.join("; "));
      }
      if (publicState.summary) pubLines.push(`Story so far: ${publicState.summary}`);
      const publicStateBlock = pubLines.join("\n");

      // Extract recent narrations from history for voice continuity.
      // Pull the last 3 assistant narrations (from stripped history).
      const recentNarrations = [];
      const assistantMsgs = apiHistory.filter(m => m.role === "assistant");
      const tail3 = assistantMsgs.slice(-3);
      for (const am of tail3) {
        const content = typeof am.content === "string"
          ? am.content
          : (am.content?.[0]?.text || "");
        try {
          const obj = JSON.parse(content);
          if (obj.narration) recentNarrations.push(obj.narration);
        } catch {
          // If we can't parse, skip — the narrator can still work without it.
        }
      }

      const narratorContext = [
        "[PUBLIC GAME STATE — what the player currently knows]",
        publicStateBlock,
        "",
        recentNarrations.length > 0
          ? `[RECENT NARRATION — for voice and style continuity]\n${recentNarrations.join("\n\n---\n\n")}`
          : "",
        "",
        `[NARRATOR BRIEF — what to depict this turn]\n${gmParsed.narrator_brief}`,
      ].filter(Boolean).join("\n\n");

      const narratorMsgs = [{ role: "user", content: narratorContext }];

      // Narrator call: max_tokens 1500 is ample for prose narration only.
      // Higher temperature (0.8) for expressive prose: the brief acts as
      // a hard container (Narrator can't see hidden state, can't control
      // logic), so creative sampling variance produces better literary
      // texture within those guardrails.
      const narratorReply = await callAPI(narratorSys, narratorMsgs, true, MODEL_CONTINUATION, 1500, 0.8, true, controller.signal, NARRATOR_TOOL);
      if (controller.signal.aborted) return;

      const narratorParsed = parseNarratorResponse(narratorReply);
      if (narratorParsed.malformed) {
        throw new BorrowedError(
          "The hour stumbles. Try once more.",
          narratorParsed.diagnostic ||
            "Narrator response was malformed (likely truncated)."
        );
      }

      // ---------------------------------------------------------------
      // COMBINE: assemble the assistant message in the same format as
      // the old single-call approach so all downstream code (stripping,
      // save/load, undo, meta mode) works unchanged.
      // ---------------------------------------------------------------
      const combinedResponse = JSON.stringify({
        gm_scratchpad: "", // stripped from history anyway; GM call had it
        narration: narratorParsed.narration,
        state: gmParsed.state,
        ...(gmParsed.ending ? { ending: gmParsed.ending } : {}),
      });

      setHistory([...newHistory, { role: "assistant", content: combinedResponse }]);
      setEntries([
        ...newEntries,
        { type: "narration", text: narratorParsed.narration, fullyRevealed: false },
      ]);
      if (gmParsed.state && !(isStateEmpty(gmParsed.state) && !isStateEmpty(gameState))) {
        setGameState(gmParsed.state);
      }
      if (gmParsed.ending) setEnded(true);
    } catch (e) {
      if (controller.signal.aborted) return;
      const cancelled =
        e instanceof BorrowedError &&
        e.detail === "Request cancelled by the player.";
      if (!cancelled) {
        setError(formatError(e));
      }
      rollback();
    } finally {
      if (abortRef.current?.controller === controller) {
        setLoading(false);
        abortRef.current = null;
      }
    }
  };

  // Player-initiated cancellation. Synchronous and unconditional: we run the
  // rollback immediately so the UI returns to a ready state in the same
  // frame the player taps STOP, then call abort() to give the underlying
  // fetch a chance to terminate. We do NOT wait for the abort to propagate
  // through the runtime's fetch wrapper — see the abortRef comment above
  // for why that's important here. If the request eventually returns
  // anyway, the call site will check controller.signal.aborted after the
  // await and discard the response.
  //
  // The function is idempotent and safe to call when nothing is in flight
  // (no-op when abortRef is null).
  const cancelRequest = () => {
    const ref = abortRef.current;
    if (!ref) return;
    const { controller, rollback } = ref;
    // Clear the ref first so a second STOP click during the same frame
    // doesn't re-run rollback against already-restored state.
    abortRef.current = null;
    // Flip loading off and undo any in-flight state changes synchronously.
    setLoading(false);
    setError(null);
    try {
      rollback?.();
    } catch {
      // A rollback closure should never throw, but if one does, don't let
      // it block the abort below — the network call is more important to
      // stop than a single state-restoration step.
    }
    // Attempt the actual fetch abort. May or may not propagate; harmless
    // if it doesn't. Guard against double-abort just in case.
    if (controller && !controller.signal.aborted) {
      try { controller.abort(); } catch {}
    }
  };

  const onKeyDown = (e) => {
    if (e.key === "Enter" && !e.shiftKey) {
      e.preventDefault();
      submit();
      return;
    }

    // Up/Down arrow input history — only when cursor is at the very start (Up)
    // or very end (Down), so multiline editing still works normally.
    const ta = textareaRef.current;
    if (!ta || inputHistory.length === 0) return;

    if (e.key === "ArrowUp" && ta.selectionStart === 0 && ta.selectionEnd === 0) {
      e.preventDefault();
      const newIndex =
        inputHistoryIndex === -1
          ? inputHistory.length - 1
          : Math.max(0, inputHistoryIndex - 1);
      setInputHistoryIndex(newIndex);
      setInput(inputHistory[newIndex]);
      // Place cursor at the end of the recalled text on next paint
      requestAnimationFrame(() => {
        if (textareaRef.current) {
          const v = textareaRef.current.value;
          textareaRef.current.setSelectionRange(v.length, v.length);
          textareaRef.current.style.height = "auto";
          textareaRef.current.style.height =
            Math.min(textareaRef.current.scrollHeight, 160) + "px";
        }
      });
      return;
    }

    if (
      e.key === "ArrowDown" &&
      ta.selectionStart === ta.value.length &&
      ta.selectionEnd === ta.value.length &&
      inputHistoryIndex !== -1
    ) {
      e.preventDefault();
      const newIndex = inputHistoryIndex + 1;
      if (newIndex >= inputHistory.length) {
        setInputHistoryIndex(-1);
        setInput("");
      } else {
        setInputHistoryIndex(newIndex);
        setInput(inputHistory[newIndex]);
      }
      requestAnimationFrame(() => {
        if (textareaRef.current) {
          const v = textareaRef.current.value;
          textareaRef.current.setSelectionRange(v.length, v.length);
          textareaRef.current.style.height = "auto";
          textareaRef.current.style.height =
            Math.min(textareaRef.current.scrollHeight, 160) + "px";
        }
      });
    }
  };

  const onInputChange = (e) => {
    setInput(e.target.value);
    if (textareaRef.current) {
      textareaRef.current.style.height = "auto";
      textareaRef.current.style.height =
        Math.min(textareaRef.current.scrollHeight, 160) + "px";
    }
  };

  // Undo: roll back the most recent player turn (action + GM response).
  // Restores prior gameState by re-parsing the now-latest assistant response.
  const canUndo = () => {
    if (loading || metaMode) return false;
    // Need at least one player turn beyond the opening to undo.
    // History layout: [user "Begin.", assistant opening, user turn1, assistant turn1, ...]
    // So we need history.length >= 4.
    return history.length >= 4 && entries.length >= 3;
  };

  const undoLastTurn = () => {
    if (!canUndo()) return;

    const newHistory = history.slice(0, -2);
    const newEntries = entries.slice(0, -2);

    // Recompute current gameState from the new last assistant message
    let newState = EMPTY_STATE;
    const lastAssistant = [...newHistory].reverse().find((h) => h.role === "assistant");
    if (lastAssistant) {
      const parsed = parseGMResponse(lastAssistant.content);
      if (parsed.state) newState = parsed.state;
    }

    setHistory(newHistory);
    setEntries(newEntries);
    setGameState(newState);
    setEnded(false);
    setError(null);

    // Entries retain their fullyRevealed flag from when they originally
    // finished typing, so TypewriterText renders them instantly. No special
    // re-reveal needed.
    setSaveBanner({ kind: "ok", text: "The last turn is unmade." });
  };

  const enterMetaMode = () => {
    setMetaMode(true);
    setMetaMessages([]);
    // Focus the input on next tick
    setTimeout(() => {
      if (textareaRef.current) textareaRef.current.focus();
    }, 50);
  };

  const exitMetaMode = () => {
    setMetaMode(false);
    setMetaMessages([]);
  };

  const restart = () => {
    setPhase("title");
    setPremise(null);
    setEntries([]);
    setHistory([]);
    setInput("");
    setError(null);
    setEnded(false);
    setGameState(EMPTY_STATE);
    setShowLedger(false);
    setInputHistory([]);
    setInputHistoryIndex(-1);
    setMetaMode(false);
    setMetaMessages([]);
  };

  // Saves

  const loadSaveList = async () => {
    setSaveListLoading(true);
    try {
      const result = await window.storage.list(SAVE_PREFIX);
      const keys = result?.keys || [];
      const saves = [];
      let totalBytes = 0;
      for (const key of keys) {
        try {
          const r = await window.storage.get(key);
          if (r?.value) {
            const size = estimateSize(r.value);
            totalBytes += size.bytes;
            const parsed = JSON.parse(r.value);
            saves.push({ key, size, ...parsed });
          }
        } catch {}
      }
      saves.sort((a, b) => (b.savedAt || 0) - (a.savedAt || 0));
      setSaveList(saves);
      setSavesTotalBytes(totalBytes);
    } catch {
      setSaveList([]);
      setSavesTotalBytes(0);
    } finally {
      setSaveListLoading(false);
    }
  };

  const openSavesModal = async () => {
    setShowSaves(true);
    await loadSaveList();
  };

  const saveCurrent = async () => {
    if (!premise || entries.length === 0) return;
    const id = Date.now().toString(36);
    const key = SAVE_PREFIX + id;
    const payload = {
      id,
      premiseId: premise.id,
      premise, // store full premise so custom hours can be reconstructed
      title: premise.title,
      realm: premise.realm,
      realmLabel: premise.realmLabel,
      isCustom: !!premise.isCustom,
      savedAt: Date.now(),
      turns: entries.filter((e) => e.type === "action").length,
      ended,
      gameState,
      entries: entries.map((e) => ({ ...e, fullyRevealed: true })),
      history,
      // Persist post-game discussion. metaMessages are flagged fully revealed
      // so they don't re-typewriter on load. metaMode tells loadSave whether
      // the player was actively in the discussion view when they saved.
      metaMessages: metaMessages.map((m) => ({ ...m, fullyRevealed: true })),
      metaMode,
      // Persist the language so the chronicle resumes in the same tongue
      // it was started in. Older saves without this field default to English
      // on load.
      language,
    };

    // Cap enforcement. Look at what's there before we add another entry —
    // if we're already at or beyond SAVE_CAP, refuse and tell the player to
    // release some. We deliberately do NOT auto-evict the oldest; data loss
    // happening silently is a worse failure mode than a clear refusal.
    try {
      const existing = await window.storage.list(SAVE_PREFIX);
      const existingCount = existing?.keys?.length || 0;
      if (existingCount >= SAVE_CAP) {
        setSaveBanner({
          kind: "err",
          text: `${SAVE_CAP} hours already kept — release one to make room.`,
        });
        // Surface the modal so the player can act immediately on the message
        // rather than hunting for the right button.
        await openSavesModal();
        return;
      }
    } catch {
      // Listing failed — proceed with the save attempt and let the write
      // error path catch quota issues. Better to try than to gate.
    }

    const serialized = JSON.stringify(payload);
    const size = estimateSize(serialized);
    try {
      await window.storage.set(key, serialized);
      // Cheerful banner; embed the rough size so the player has a sense of
      // what they just spent of their storage budget. Localized formatting
      // is overkill here — these are reference numbers, not currency.
      setSaveBanner({
        kind: "ok",
        text: `The hour is set aside. (${formatKB(size.kb)} · ${formatTokens(size.tokens)})`,
      });
      await loadSaveList();
    } catch (e) {
      // window.storage rejections include quota messages on some platforms;
      // surface a hint when the error message looks quota-shaped, and a
      // generic message otherwise. Don't try to parse JSON quotas — text
      // matching is robust to wording changes.
      const msg = (e && e.message) || "";
      const looksQuota = /quota|limit|too large|size|5\s*mb/i.test(msg);
      setSaveBanner({
        kind: "err",
        text: looksQuota
          ? "Could not set the hour aside — the save exceeds the storage limit. Try releasing other hours first."
          : "Could not set the hour aside.",
      });
    }
  };

  const loadSave = async (save) => {
    // For custom hours the full premise is stored in the save; for built-ins
    // we look it up by id (so prompt updates take effect on resume).
    let found = null;
    if (save.isCustom && save.premise) {
      found = save.premise;
    } else {
      found = PREMISES.find((p) => p.id === save.premiseId) || save.premise || null;
    }
    if (!found) {
      setSaveBanner({ kind: "err", text: "This hour is no longer here." });
      return;
    }
    setPremise(found);
    setEntries((save.entries || []).map((e) => ({ ...e, fullyRevealed: true })));
    setHistory(save.history || []);
    setInput("");
    setError(null);
    setEnded(!!save.ended);
    setGameState(save.gameState || EMPTY_STATE);
    // Older saves predate the language field; English is the right fallback
    // because every chronicle saved before this feature was authored in English.
    setLanguage(save.language || DEFAULT_LANGUAGE);
    setShowLedger(false);
    setInputHistory([]);
    setInputHistoryIndex(-1);
    // Restore post-game discussion if it was saved. Older saves without
    // these fields default to an empty conversation, which is correct.
    setMetaMessages(
      (save.metaMessages || []).map((m) => ({ ...m, fullyRevealed: true }))
    );
    setMetaMode(!!save.metaMode);
    setPhase("playing");
    setShowSaves(false);
    setSaveBanner({ kind: "ok", text: "The hour resumes." });
  };

  const deleteSave = async (key, e) => {
    e.stopPropagation();
    try {
      await window.storage.delete(key);
      await loadSaveList();
    } catch {}
  };

  // Build a clean markdown copy of the chronicle and place it on the
  // clipboard. Includes title, realm, premise teaser, the opening, every
  // exchange, and a sealing line if the hour has ended.
  //
  // includeMeta is opt-in (default false). When true and there is a
  // post-game discussion, the meta exchange is appended below the chronicle
  // as a clearly-marked appendix. We don't append it by default because the
  // chronicle proper and the director's commentary are tonally distinct
  // artifacts and many players will want one without the other.
  const exportChronicle = async (includeMeta = false) => {
    if (!premise || entries.length === 0) return;
    const lines = [];
    lines.push(`# ${premise.title}`);
    lines.push(`*${premise.realmLabel} · The Borrowed Hour*`);
    lines.push("");
    if (premise.teaser) {
      lines.push(`> ${premise.teaser}`);
      lines.push("");
    }
    lines.push("---");
    lines.push("");
    for (const entry of entries) {
      if (entry.type === "narration") {
        lines.push(entry.text.trim());
        lines.push("");
      } else if (entry.type === "action") {
        // Render player actions as blockquotes with a leading marker.
        const safe = entry.text.trim().replace(/\n/g, "\n> ");
        lines.push(`> › ${safe}`);
        lines.push("");
      }
    }
    if (ended) {
      lines.push("---");
      lines.push("");
      lines.push("*❦ The hour is spent. ❦*");
      lines.push("");
    }
    const metaIncluded = includeMeta && metaMessages.length > 0;
    if (metaIncluded) {
      lines.push("---");
      lines.push("");
      lines.push("## Director's commentary");
      lines.push("");
      lines.push("*Conversation with the author of the hour, after its close.*");
      lines.push("");
      for (const m of metaMessages) {
        if (m.role === "user") {
          const safe = m.text.trim().replace(/\n/g, "\n> ");
          lines.push(`> **You:** ${safe}`);
          lines.push("");
        } else {
          lines.push(`**The author:** ${m.text.trim()}`);
          lines.push("");
        }
      }
    }
    const text = lines.join("\n");

    const okBannerText = metaIncluded
      ? "A copy of the chronicle and the commentary is on the clipboard."
      : "A copy of the chronicle is on the clipboard.";

    // Three-tier copy strategy. Mobile clipboard support is patchy: iOS
    // Safari often blocks navigator.clipboard outside of secure contexts
    // and very specific gesture timing; the legacy execCommand path works
    // in more contexts but is also unreliable. If both fail, we open a
    // modal with the text pre-selected so the user can long-press → Copy
    // manually. That always works.
    const tryClipboardAPI = async () => {
      if (!navigator.clipboard?.writeText) return false;
      try {
        await navigator.clipboard.writeText(text);
        return true;
      } catch {
        return false;
      }
    };

    const tryLegacyCopy = () => {
      try {
        const ta = document.createElement("textarea");
        ta.value = text;
        // Position offscreen but still selectable.
        ta.setAttribute("readonly", "");
        ta.style.position = "fixed";
        ta.style.top = "0";
        ta.style.left = "0";
        ta.style.width = "1px";
        ta.style.height = "1px";
        ta.style.opacity = "0";
        document.body.appendChild(ta);
        ta.focus();
        ta.select();
        ta.setSelectionRange(0, text.length);
        const ok = document.execCommand("copy");
        document.body.removeChild(ta);
        return ok;
      } catch {
        return false;
      }
    };

    if (await tryClipboardAPI()) {
      setSaveBanner({ kind: "ok", text: okBannerText });
      return;
    }
    if (tryLegacyCopy()) {
      setSaveBanner({ kind: "ok", text: okBannerText });
      return;
    }
    // Final fallback — open a modal with the text pre-selected. The user
    // long-presses (mobile) or Ctrl+C (desktop) to copy manually.
    setExportFallbackText(text);
  };

  // Mark an entry / meta message as fullyRevealed when its TypewriterText
  // finishes typing. Functional setters so concurrent updates compose.
  const markEntryRevealed = (index) => {
    setEntries((prev) =>
      prev.map((e, i) => (i === index ? { ...e, fullyRevealed: true } : e))
    );
  };
  const markMetaRevealed = (index) => {
    setMetaMessages((prev) =>
      prev.map((m, i) => (i === index ? { ...m, fullyRevealed: true } : m))
    );
  };

  // Aria-live region: announces the most recently completed narration to
  // assistive tech without re-reading the entire chronicle. We pick the
  // last narration entry that's been fully revealed — typewriter-in-progress
  // text would otherwise be announced in fragments. Meta-discussion replies
  // also flow through here when in metaMode. The region itself is sr-only
  // (visually hidden, accessibility-tree present); aria-atomic="true" tells
  // the screen reader to announce the new value as a single unit rather
  // than diffing against the previous one.
  const liveRegionText = (() => {
    if (metaMode) {
      const lastMeta = [...metaMessages].reverse().find(
        (m) => m.role === "assistant" && m.fullyRevealed
      );
      return lastMeta?.text || "";
    }
    const lastEntry = [...entries].reverse().find(
      (e) => e.type === "narration" && e.fullyRevealed
    );
    return lastEntry?.text || "";
  })();

  return (
    <div
      className={`borrowed-root borrowed-vignette borrowed-grain min-h-screen relative overflow-hidden${
        settings.highContrast ? " high-contrast" : ""
      }`}
    >
      <style>{STYLES}</style>
      {/* Aria-live announce region — visually hidden, screen-reader present.
          Updates with the latest fully-revealed narration so the chronicle
          stays consumable when the visual typewriter is bypassed by
          assistive tech. polite (vs assertive) waits for a pause in
          speech — appropriate; new narration isn't an emergency. */}
      <div className="sr-only" aria-live="polite" aria-atomic="true">
        {liveRegionText}
      </div>
      <div className="relative z-10">
        {phase === "title" ? (
          <TitleScreen
            onChoose={beginAdventure}
            onOpenSaves={openSavesModal}
            onOpenCustom={() => setShowCustom(true)}
            onOpenSettings={() => setShowSettings(true)}
            language={language}
            onChangeLanguage={setLanguage}
            loading={loading}
            error={error}
          />
        ) : (
          <GameScreen
            premise={premise}
            entries={entries}
            skipNonce={skipNonce}
            instantReveal={instantReveal}
            onEntryDone={markEntryRevealed}
            onMetaDone={markMetaRevealed}
            loading={loading}
            loadingPhrase={loadingPhrase}
            error={error}
            ended={ended}
            metaMode={metaMode}
            metaMessages={metaMessages}
            onEnterMeta={enterMetaMode}
            onExitMeta={exitMetaMode}
            onOpenLedger={() => setShowLedger(true)}
            onOpenSettings={() => setShowSettings(true)}
            canUndo={canUndo()}
            onUndo={undoLastTurn}
            input={input}
            onInputChange={onInputChange}
            onKeyDown={onKeyDown}
            onSubmit={submit}
            onSkip={skipReveal}
            onCancel={cancelRequest}
            onRestart={restart}
            onSave={saveCurrent}
            onOpenSaves={openSavesModal}
            onExport={exportChronicle}
            saveBanner={saveBanner}
            scrollRef={scrollRef}
            textareaRef={textareaRef}
          />
        )}

        {showSaves && (
          <SavesModal
            saves={saveList}
            totalBytes={savesTotalBytes}
            cap={SAVE_CAP}
            loading={saveListLoading}
            onClose={() => setShowSaves(false)}
            onLoad={loadSave}
            onDelete={deleteSave}
            inGame={phase === "playing"}
          />
        )}

        {showSettings && (
          <SettingsModal
            settings={settings}
            onChange={updateSetting}
            onClose={() => setShowSettings(false)}
            osReducedMotion={osReducedMotion}
          />
        )}

        {showLedger && premise && (
          <LedgerModal
            premise={premise}
            gameState={gameState}
            onClose={() => setShowLedger(false)}
          />
        )}

        {showCustom && (
          <CustomModal
            onClose={() => setShowCustom(false)}
            onBegin={(description) => {
              setShowCustom(false);
              beginAdventure(buildCustomPremise(description));
            }}
            disabled={loading}
          />
        )}

        {exportFallbackText !== null && (
          <ExportFallbackModal
            text={exportFallbackText}
            onClose={() => setExportFallbackText(null)}
          />
        )}
      </div>
    </div>
  );
}

function realmGlyph(realm) {
  switch (realm) {
    case "echo":  return "◷";
    case "neon":  return "◈";
    case "omen":  return "✦";
    case "dream": return "❋";
    case "wild":  return "✷";
    default:      return "·";
  }
}

function SavesModal({ saves, totalBytes = 0, cap = SAVE_CAP, loading, onClose, onLoad, onDelete, inGame }) {
  // The release button is two-tap to prevent accidental deletion. First tap
  // arms one specific save (button switches to "CONFIRM RELEASE"), second tap
  // commits. Tapping a different save's button moves the arming. Auto-disarms
  // after 4 seconds. Tapping outside the row also disarms.
  const [armedKey, setArmedKey] = useState(null);
  useEffect(() => {
    if (!armedKey) return;
    const t = setTimeout(() => setArmedKey(null), 4000);
    return () => clearTimeout(t);
  }, [armedKey]);

  const handleReleaseTap = (key, e) => {
    e.stopPropagation();
    if (armedKey === key) {
      setArmedKey(null);
      onDelete(key, e);
    } else {
      setArmedKey(key);
    }
  };

  // Threshold at which to visibly flag the count of kept hours — we don't
  // wait until the cap to surface that the player is approaching it. Two
  // tiers: 'warn' (yellow-amber) at >=80%, 'full' (rose-ember) at the cap.
  const ratio = saves.length / cap;
  const countTone =
    saves.length >= cap ? "full" : ratio >= 0.8 ? "warn" : "ok";
  const countColor =
    countTone === "full"
      ? "var(--rose-ember)"
      : countTone === "warn"
      ? "var(--rose-gold)"
      : "var(--cream-dim)";
  const totalKB = totalBytes / 1024;

  return (
    <div
      className="modal-backdrop"
      onClick={() => {
        setArmedKey(null);
        onClose();
      }}
    >
      <div
        className="modal-panel"
        onClick={(e) => {
          // Tapping anywhere in the panel that isn't the armed button itself
          // also disarms. The button has stopPropagation so it survives.
          setArmedKey(null);
          e.stopPropagation();
        }}
      >
        <div
          className="px-6 py-5 border-b flex items-center justify-between"
          style={{ borderColor: "rgba(232, 222, 197, 0.1)" }}
        >
          <div>
            <div
              className="display-font text-[10px] mb-1"
              style={{ color: "var(--cream-faint)", letterSpacing: "0.4em" }}
            >
              HOURS SET ASIDE
            </div>
            <h2
              className="display-font text-xl"
              style={{ color: "var(--cream-bright)", letterSpacing: "0.04em" }}
            >
              Take an hour up again
            </h2>
            {/* Storage usage line. Surfaces three numbers in a single
                ledger-style row: how many of the cap are spent, how much
                disk this costs, and a token-equivalent so the player has
                a sense of input scale (relevant if they're thinking about
                the chronicle as something to feed back into a model or
                worry about reaching limits). Color-coded by saturation. */}
            {!loading && saves.length > 0 && (
              <div
                className="body-font italic mt-1 flex flex-wrap gap-x-3"
                style={{ fontSize: 12, color: "var(--cream-dim)" }}
              >
                <span style={{ color: countColor }}>
                  {saves.length} of {cap} kept
                  {countTone === "full" && " — full"}
                  {countTone === "warn" && " — nearing the cap"}
                </span>
                <span>·</span>
                <span>{formatKB(totalKB)} in total</span>
                <span>·</span>
                <span>
                  {formatTokens(Math.round(totalBytes / APPROX_CHARS_PER_TOKEN))}
                </span>
              </div>
            )}
          </div>
          <button
            onClick={onClose}
            className="display-font text-sm"
            style={{ color: "var(--cream-dim)", letterSpacing: "0.2em" }}
            aria-label="Close"
          >
            ✕
          </button>
        </div>

        <div className="overflow-y-auto px-6 py-5 space-y-3" style={{ minHeight: 200 }}>
          {loading ? (
            <div className="text-center body-font italic py-12" style={{ color: "var(--cream-dim)" }}>
              Counting the hours
              <span className="typing-dots">
                <span>.</span>
                <span>.</span>
                <span>.</span>
              </span>
            </div>
          ) : saves.length === 0 ? (
            <div className="text-center body-font italic py-12" style={{ color: "var(--cream-faint)" }}>
              No hours set aside yet.
              {inGame && (
                <div className="mt-2 text-sm">
                  Use ❀ SET ASIDE to keep your current hour.
                </div>
              )}
            </div>
          ) : (
            saves.map((save) => (
              <button key={save.key} className="save-row" onClick={() => onLoad(save)}>
                <div className="flex-1 min-w-0">
                  <div className="flex items-center gap-2 mb-1 flex-wrap">
                    <span
                      className={`realm-pill realm-${save.realm}`}
                      style={{ fontSize: 8, padding: "2px 7px" }}
                    >
                      {realmGlyph(save.realm)} {save.realmLabel || save.realm?.toUpperCase()}
                    </span>
                    <span
                      className="display-font text-base"
                      style={{ color: "var(--cream-bright)", letterSpacing: "0.02em" }}
                    >
                      {save.title}
                    </span>
                  </div>
                  <div
                    className="body-font italic text-sm flex flex-wrap gap-x-3 items-center"
                    style={{ color: "var(--cream-dim)" }}
                  >
                    <span>{save.turns || 0} turns taken</span>
                    <span>·</span>
                    <span>{formatRelative(save.savedAt)}</span>
                    {save.size && (
                      <>
                        <span>·</span>
                        <span
                          title={`${formatKB(save.size.kb)} on disk · ${formatTokens(save.size.tokens)} if reloaded`}
                          style={{ color: "var(--cream-faint)" }}
                        >
                          {formatKB(save.size.kb)} · {formatTokens(save.size.tokens)}
                        </span>
                      </>
                    )}
                    {save.ended && (
                      <>
                        <span>·</span>
                        <span
                          className="display-font"
                          style={{
                            color: "var(--rose-gold)",
                            fontSize: 9,
                            letterSpacing: "0.3em",
                          }}
                        >
                          ❦ COMPLETE
                        </span>
                      </>
                    )}
                  </div>
                </div>
                <span
                  onClick={(e) => handleReleaseTap(save.key, e)}
                  className="icon-btn icon-btn-danger"
                  style={{
                    padding: "5px 10px",
                    fontSize: 9,
                    background: armedKey === save.key ? "rgba(180, 70, 70, 0.25)" : undefined,
                    borderColor: armedKey === save.key ? "rgba(220, 100, 100, 0.7)" : undefined,
                    color: armedKey === save.key ? "rgba(255, 200, 200, 1)" : undefined,
                  }}
                  role="button"
                  tabIndex={0}
                  onKeyDown={(e) => {
                    if (e.key === "Enter" || e.key === " ") handleReleaseTap(save.key, e);
                  }}
                  title={
                    armedKey === save.key
                      ? "Tap again to release this hour permanently"
                      : "Release this hour (tap, then confirm)"
                  }
                  aria-label={
                    armedKey === save.key
                      ? `Confirm releasing ${save.title}`
                      : `Release ${save.title}`
                  }
                >
                  {armedKey === save.key ? "✕ CONFIRM" : "RELEASE"}
                </span>
              </button>
            ))
          )}
        </div>
      </div>
    </div>
  );
}

function formatRelative(ts) {
  if (!ts) return "—";
  const diff = Date.now() - ts;
  const m = Math.floor(diff / 60000);
  if (m < 1) return "moments ago";
  if (m < 60) return `${m} minute${m === 1 ? "" : "s"} ago`;
  const h = Math.floor(m / 60);
  if (h < 24) return `${h} hour${h === 1 ? "" : "s"} ago`;
  const d = Math.floor(h / 24);
  if (d < 30) return `${d} day${d === 1 ? "" : "s"} ago`;
  return new Date(ts).toLocaleDateString();
}

function CustomModal({ onClose, onBegin, disabled }) {

        <div
          className="px-6 py-5 border-b flex items-center justify-between"
          style={{ borderColor: "rgba(232, 222, 197, 0.1)" }}
        >
          <div>
            <div
              className="display-font text-[10px] mb-1"
              style={{ color: "var(--wild)", letterSpacing: "0.4em" }}
            >
              ✷ THE UNWRITTEN HOUR
            </div>
            <h2
              className="display-font text-xl"
              style={{ color: "var(--cream-bright)", letterSpacing: "0.04em" }}
            >
              Describe your scenario
            </h2>
          </div>
          <button
            onClick={onClose}
            className="display-font text-sm"
            style={{ color: "var(--cream-dim)", letterSpacing: "0.2em" }}
          >
            ✕
          </button>
        </div>

        <div className="overflow-y-auto px-6 py-5 space-y-4">
          <p
            className="body-font italic text-sm"
            style={{ color: "var(--cream-dim)", lineHeight: 1.6 }}
          >
            Describe enough to set the hour. Tell us where you are, what is
            happening, what is at stake — and most of all,{" "}
            <span style={{ color: "var(--cream-bright)" }}>
              who you are
            </span>
            : a name, a calling, a fear or appetite, a small particular truth
            that gives the hour a soul to pour through. A paragraph is plenty;
            even rich sentences will do.
          </p>
          <textarea
            ref={ref}
            value={text}
            onChange={(e) => setText(e.target.value)}
            onKeyDown={(e) => {
              if (e.key === "Enter" && (e.metaKey || e.ctrlKey)) {
                e.preventDefault();
                handleBegin();
              }
            }}
            placeholder="Example: A lighthouse keeper on a remote island during a long winter. Three nights ago a ship was wrecked on the rocks below — but the bodies on the beach are not from any crew you know, and they are wearing uniforms from a war that ended a hundred years ago. Tonight, something is climbing the spiral stair."
            className="borrowed-input w-full px-4 py-3 resize-y text-base"
            style={{
              minHeight: "180px",
              maxHeight: "320px",
              fontFamily: "'Cormorant Garamond', serif",
              lineHeight: 1.55,
              borderColor: "rgba(184, 200, 150, 0.25)",
            }}
          />
          <div
            className="text-xs italic body-font flex items-center justify-between"
            style={{ color: "var(--cream-faint)" }}
          >
            <span>
              {tooShort
                ? "A little more, please — at least 30 characters."
                : `${text.trim().length} characters · ⌘/Ctrl + ↵ to begin`}
            </span>
          </div>
        </div>

        <div
          className="px-6 py-4 border-t flex items-center justify-end gap-3"
          style={{ borderColor: "rgba(232, 222, 197, 0.1)" }}
        >
          <button
            onClick={onClose}
            className="icon-btn"
            style={{ padding: "8px 18px" }}
          >
            CANCEL
          </button>
          <button
            onClick={handleBegin}
            disabled={tooShort || disabled}
            className="icon-btn"
            style={{
              padding: "8px 22px",
              borderColor: "var(--wild-border)",
              color: "var(--wild)",
            }}
          >
            ✷ BEGIN THIS HOUR
          </button>
        </div>
      </div>
    </div>
  );
}
